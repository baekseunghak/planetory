# Planetory 클릭 프로토타입

요구사항 명세서 v0.8·와이어프레임 v0.3의 화면 구조를 확정하는 데 쓴 단일 HTML 프로토타입입니다. 실제 TESS 데이터(별 30여 개의 후보표·곡선 요약)를 넣어 홈 별 지도 → 분석 → 결과 → 커뮤니티·통계·마이페이지 흐름을 클릭해 볼 수 있습니다. 서버 없이 동작하며 진행 상태는 브라우저 localStorage에만 저장됩니다(시연용, NFR-19 참고).

- 아티팩트(바로 열기): https://claude.ai/code/artifact/923ec760-c2a9-4c26-85a7-2404e8a8d0a9
- 빌드 결과물: `planetory-prototype.html` (약 3.9MB, 폰트·행성 텍스처 내장)

## 파일

| 파일 | 역할 |
|---|---|
| `app.html` | 화면·스타일·로직 원본. `<!--STARS-->`, `<!--FONT-->` 자리에 아래 파일이 주입됨 |
| `stars.js` | 별·후보 데이터(`window.STARS`). TESS TOI·TCE에서 뽑은 30여 개 별의 후보표와 곡선 요약 |
| `planets.js` | 행성 3D 모델(ToyPlanets OBJ 변환)과 텍스처(`window.TOY`, `window.TOYTEX`, data URI) |
| `Pretendard.woff2` | 화면 폰트 |
| `build.py` | 위 파일을 합쳐 `planetory-proto.html`(본문만)과 `index.html`(doctype 포함)을 만듦 |
| `planetory-prototype.html` | 빌드 결과물. 이 파일만 열어도 동작 |

## 빌드

```bash
python build.py
```

`index.html`이 생성됩니다. 저장소에는 `planetory-prototype.html` 이름으로 올렸으니 빌드 후 이름을 맞춰 복사합니다.

## 실행

파일을 브라우저에서 직접 열거나(three.js는 cdnjs에서 로드) 정적 서버로 여세요.

```bash
python -m http.server 8769
```

데스크톱 폭 1024px 이상 기준입니다(NFR-17). 상태 초기화는 브라우저 콘솔에서 `__proto.reset()` 실행 또는 localStorage 키 `planetory-proto-v3` 삭제.

## 프로토타입에서 확정한 규칙 (SRS v0.8 시점 기준)

> 이 프로토타입은 SRS v0.8·와이어프레임 v0.3 시점의 스냅샷이다. 현행 정본과 상세 문서는 [요구사항 문서 안내](../README.md)에서 확인하며, 아래 규칙 중 등급·별 열림·성과 조건은 이후 개정되었다.

- 홈: 검은 연속 캔버스, 튜토리얼·챌린지 별 중앙, 새 별은 부모 별 바깥 세대별 반지름에 불규칙 배치. 별 색 = 찾은 행성 수(0/1/2/3/4+), 행성 없이 완료는 살구색. 궤도는 확인된 행성 + "행성 같음" 판단 신호만, 회색 실선. 축소 시 성운 군집.
- 분석: 단계형(봉우리 → 주기 → 구간 → 판단 → 제출), 원본 곡선과 반복 주기 그래프 나란히, 관측기간/2 초과 구간 음영, 찾을 수 있는 신호가 없으면 시스템 자동 완료(SUB-11).
- 결과 카드에 AI 점수 구간과 다른 사람들의 판단(인정된 제출 기준). 별 결과 페이지(RES-10).
- 커뮤니티는 스레드형 피드, 반응은 동의/비동의. 통계 3탭. 마이페이지가 옛 "내 진행"을 흡수.
- 화면 문구는 당시 용어 사전 v0.1 표기(현행 v0.4로 개정됨).

프로토타입에서 아직 목업만인 것: 팔로우(P1), 설정 항목 동작, 알림, 운영 화면.

## 현재 별지도 기준 안내

이 디렉터리의 정적 앱은 과거 화면/정책 검증 자료다. 현재 나선 은하의 외형과 색/크기·선택 근접 뷰는 [개인 시제품 기준 자료](../../development/sky-reference/README.md)를 따른다. 이 앱의 방사형/행성 수별 색·전체 지도 궤도를 현행 규칙으로 복원하지 않는다.
