# Planetory 용어 사전 v1.0.1 (2026-09-16)

SRS v1.3.1 접기 조작 변경안에 동기화한다. 사용자 채택·교차 리뷰 대기이며 구현 완료를 뜻하지 않는다.

원칙
1. 화면에는 쉬운 말만 쓴다. 정확한 용어는 툴팁·괄호·문서에만 둔다.
2. 한 화면에 핵심 메시지는 하나. 숫자와 근거는 접힌 상세로 내린다.
3. 정답·오답·행성을 발견·맞춘 개수 같은 표현은 쓰지 않는다(SRS 8장).
4. 측정하지 않은 값은 긍정·부정 판단처럼 쓰지 않고 `데이터 없음`으로 명시한다.
5. 신호 매칭, 내 판단의 일치 여부, 성과 인정, 별 탐색 완료, 분석 공개는 서로 다른 의미로 표시한다.
6. 요구사항 명세서 v1.3.1·상태표 v1.3.1 변경안을 따른다. 배치 위치는 이 사전이 정하지 않는다.
