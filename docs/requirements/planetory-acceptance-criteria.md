# 통합 검수 시나리오와 정책 추적

> 상위 정본: [요구사항 명세서](planetory-requirements-spec.md)

## 9. 통합 검수 시나리오

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| AT-01 | SSAFY·Google 최초 로그인과 재로그인 | 같은 제공자 고유 ID는 같은 회원, 다른 제공자는 임의 병합되지 않음 |
| AT-02 | 비회원이 로그인 화면 외 서비스 URL·API·공개 게시글 직접 주소에 접근 | 로그인으로 이동하거나 인증 오류를 반환하고 별·게시글·댓글·분석 데이터가 노출되지 않음 |
| AT-03 | 확정 행성 보유 별을 홈과 분석 화면에서 제출 전에 조회 | 홈에서는 숨기고 분석 화면에서는 후보표에 있는 확정 후보 기준으로 보유 여부만 표시 `(v0.3)` |
| AT-04 | 확정 대상 상세 공개 | 매칭 후 또는 [상세 보기] 선택 후에만 상세값·출처·참고 링크 공개 `(v0.3)` |
| AT-05 | 미확정 대상 제출 | 자체 BLS 비교와 AI 점수·상태·모델 버전을 참고값으로 표시하고 확정 표현을 사용하지 않음 |
| AT-06 | 접힌 곡선에서 transit 위상 시작·끝을 선택 | 브라우저가 미리보기 epoch·duration을 즉시 계산하고 시간 영역 곡선의 모든 예상 transit에 읽기 전용 밴드를 동기화한다. 시간 영역에서는 구간을 선택·수정할 수 없고 duration 숫자 입력도 없다. 접힌 곡선 핸들을 바꾸면 네트워크 응답을 기다리지 않고 미리보기 파생값과 밴드가 함께 갱신된다. 제출하면 서버가 원본 위상값으로 epoch·duration을 다시 계산·검증한다. `(v0.11)` |
| AT-07 | 사용자 판단 제출 | LIKELY_PLANET, UNLIKELY_PLANET, UNSURE만 허용하고 표시 문구·저장값·분석 히스토리가 일치함 |
| AT-08 | 후보 매칭 후 다음 후보 탐색 | 동일 Bundle·제거 조합의 온라인 캐시가 있으면 잔차 곡선·주기도를 즉시 제공한다. 캐시가 없으면 잔차 계산 → 잔차 준비 → 주기도 계산 순서를 표시하고 완료 후 잔차 단계로 전환한다. 원본으로 복귀할 수 있다. `(v0.11)` |
| AT-09 | 입력 경계값 제출 | 0·음수·무한대 period, 위상 범위 밖·폭 0·폭 ≥ 1·DEC-19 제한 위반을 거절하고 성과가 없다. `phase_start < 1 < phase_end`인 정상 경계 통과는 허용하며 서버가 epoch·duration을 다시 산정한다. `(v0.11)` |
| AT-10 | 같은 주기지만 다른 위상 제출 | 다른 통과를 설명하면 미매칭 또는 모호성 처리, 잘못된 성과·등급 반영 없음 |
| AT-11 | P/2 또는 2P 제출 | 대표 주기로 자동 정정하고 원본·정정값·배율을 저장하며 동일 고유 후보 성과로 처리 |
| AT-12 | 동일 후보 반복·동시·재전송 | duplicate 또는 기존 응답을 반환하고 UserCandidateAchievement와 후보 수가 중복되지 않음 |
| AT-13 | 여러 후보가 동시에 일치 | 안전한 우세 후보가 없으면 ambiguous_match로 처리하고 임의 성과·등급 없음 |
| AT-14 | 후보표와 불일치 | 저장 후보 미일치 안내, 행성 부재 단정 없음 |
| AT-15 | AI 입력 부족과 추론 오류 | 서로 다른 실행 상태, 0점이나 미충족으로 왜곡하지 않음 |
| AT-16 | 외부 확정 신호의 AI 점수가 낮음 | 외부 확정과 AI 결과를 구분 표시, 확정 상태 유지 |
| AT-17 | TCE와 자체 BLS 값이 다름 | 자체 BLS가 대표값, TCE는 출처 표시된 비교값. 확정 후보의 정렬은 DEC-20 |
| AT-18 | TCE-only이며 자체 BLS 미통과 | 사용자 매칭 후보에서 제외, 운영 비교 자료로 보존. 확정 보유 표시에도 반영하지 않음 `(v0.3)` |
| AT-19 | TCE가 없는 신규 데이터 | 자체 BLS와 선정 AI로 후보표 생성 가능 |
| AT-20 | BLS 통과·AI 미승인 내부 후보 제거 | 내부 잔차에서 후속 BLS 실행, AI는 제거 게이트가 아님 |
| AT-21 | 신호 제거 품질 검증 실패 | 이후 후보 공개 차단, 이전 내부 곡선·공개본 복구 |
| AT-22 | Silver 내부 잔차에서 찾은 후보 제출 | 원본 검증을 통과한 후보만 사용자 제출과 정상 연결되고, 사용자는 같은 모델·버전으로 EC2가 온라인 계산한 잔차에서 같은 후보를 찾을 수 있음 `(v0.11)` |
| AT-23 | 정상 제출 완료 | Submission과 소유자 전용 AnalysisHistory가 한 번 생성되고 제출값·판단·그래프 상태·버전이 보존됨 |
| AT-24 | 확정 행성 고유 신호 1/2/3/4개 매칭 및 LIKELY_PLANET 제출 | 성과 수 1/2/3/4로 등급 문자 A/S/SS/SSS 표시, 성과마다 별 1개 발견. 수치 매칭만 성공하고 판단 불일치·보류이면 성과 수·별 열림 없음 `(v0.13)` |
| AT-25 | 확정 FP 신호에 UNLIKELY_PLANET으로 올바르게 제출 | FP · A로 인정되며 확정 행성 수에는 포함되지 않음 |
| AT-26 | 미확정 후보 매칭 후 공개하지 않음 | 성과 미인정·히스토리 저장, 다음 곡선 요청 가능. 마지막 탐색 가능 신호면 완료 유지, [분석 공개] 표시 `(v0.12)` |
| AT-27 | 미게시 기록을 나중에 공식 분석으로 공개 | 고유 신호당 최초 미확정 성과·등급 반영. 완료·곡선 단계 유지, 일반 글 첨부는 인정 아님 `(v0.12)` |

| AT-31 | 별 게시글 댓글에 히스토리 첨부 | 댓글 작성자 본인의 원 게시글과 같은 TIC 기록만 첨부되고 자유 게시글에는 첨부 불가 |
