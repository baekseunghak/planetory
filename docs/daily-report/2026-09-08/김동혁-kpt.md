## Problem

- GCP는 계정별 크레딧·할당량·프로젝트·VPC를 각각 관리해야 함.
- 마스터 1대와 DataNode 5대의 VPC를 연결하려면 총 15개 피어링 쌍과 30개 방향별 설정이 필요함.
- DataNode 5대만 3TiB를 사용하면 원시 용량은 15TiB이며, HDFS 복제 계수 3 적용 시 이론적인 사용 가능 용량은 약 5TiB로 감소함.
- GCP는 외부 IP로 데이터 전송 시, 인터넷 아웃바운드 비용이 발생할 수 있음.
- HDFS/Spark 원본 로그와 스냅샷을 무분별하게 전송하면 인터넷 추가 비용이 증가함.
- 단일 마스터 장애 시 NameNode 메타데이터 복구가 어려운 단일 장애점이 존재함. (고려해서 설계할 필요 있음)
