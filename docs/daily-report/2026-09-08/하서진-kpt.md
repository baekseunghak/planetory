# 2026-09-08 KPT

## Keep

- 마이페이지와 별 상세 화면을 시제품으로 제작하고, 기존 별지도 제안안과 디자인을 통일해 하나의 서비스처럼 연결했다.
- NASA Eyes의 실제 화면을 활용해 TOI-270과 L 98-59의 표시 방식, 확대·축소와 드래그 동작을 브라우저에서 검증했다.
- 별지도 → 별 상세 → 분석 미리보기 → 지도 복귀 흐름을 연결하고, 화면을 이동해도 지도 방향·배율·관측 레이어와 별의 진행 상태가 유지되는지 확인했다.
- 최신 요구사항 명세서 v0.12를 확인하고, 시제품과 다른 정책 및 아직 구현하지 않은 기능을 구분해 정리했다.
- 팀원들에게 시제품을 공유하고, 명세안의 개인 지도 배치에 제안안의 미니맵을 결합하는 방향으로 의견을 정리했다. 별 이름을 마우스로 가리킬 때만 표시하고 평소에는 검은 밤하늘에 별빛이 보이게 해, 지도를 채워 나가는 동기부여를 주자는 의견도 받았다.

## Problem

- 실제 천체 좌표를 사용하는 별지도는 팀원들이 보기에 위치를 파악하고 조작하기 불편하다는 피드백을 받았다. 천체 위치를 사실적으로 보여주는 것과 사용자가 편하게 탐사를 이어가는 것 사이의 우선순위를 조정할 필요가 있었다.
- NASA 화면의 메뉴를 가리는 것은 가능했지만, 사용자 입력을 휠과 드래그로만 완전히 제한하는 문제는 해결하지 못했다.
- 튜토리얼 1개 이후 두 별을 여는 시연 흐름과 분석 전 행성 정보 공개는 명세와 차이가 있다. 시연용으로 축소한 부분과 실제 서비스에 반영할 정책을 구분해야 한다.
- 현재 마이페이지는 별을 감상하고 분석으로 이동하는 기능이 중심이며, 제출별 히스토리와 탐색 완료·성과 인정·분석 공개 상태 표시는 부족하다.
- 진행 상태는 브라우저에만 저장되고 분석 화면도 미리보기 단계여서, 실제 분석 기능과 서버를 연결하기 위한 작업 범위를 더 구체화해야 한다.

## Try

- 팀 피드백을 반영한 실제 수정은 다음 작업에서 진행하겠다. 명세안의 개인 지도 배치와 이동 방식을 기준으로, 제안안의 미니맵을 결합하는 시제품을 만들겠다.
- 지도 위의 별 이름은 마우스를 올렸을 때만 나타나도록 하고, 평소에는 검은 배경과 별빛이 중심이 되도록 표현하겠다. 탐사를 진행하며 발견한 별로 지도가 채워지는 모습을 통해 동기부여가 되는지 확인하겠다.
- 분석 프론트 담당자와 화면 진입·복귀 시 전달할 정보를 정하고, 탐색 완료·성과 인정·분석 공개 상태를 각각 구분해 표시하도록 연결 기준을 맞추겠다.
- 마이페이지의 프로필 요약, 제출 이력이 있는 별 목록, 분석 히스토리와 결과 화면 연결을 우선순위에 따라 정리하겠다.
- NASA 연동의 제약과 정보 공개 시점을 팀과 논의하고, 합의된 구현 범위를 구체적인 Jira 작업으로 나누겠다.
