# 2026-09-11 KPT

## Keep

- 일반 글·댓글의 중복 작성, 동시 수정, 삭제·숨김과 챌린지 안내 정책을 구체화하고 기능 분석 문서와 API 명세에 반영했다.
- 그래프 조회와 Redis 캐시의 데이터 판 구분, 계산 상태, 실패 처리를 정리하고 ERD의 배열 구조와 대조했다.
- API 명세를 실제 백엔드 경로인 `apps/backend/docs`로 이동하고, 검색 범위·핫 토픽 산식의 제안과 팀 확정 사항을 구분했다.
- 서비스·탐사 API의 별 목록과 성과 요약 계약을 대조해 중복 정의를 줄이고, 식별자·오류 응답·예시의 불일치를 보완했다.

## Problem

- 명세서·ERD·담당자별 문서에 같은 기능이 반복 정의되어 공개 범위, 우선순위, 응답 구조가 달라지는 부분이 있었다.
- 검색·핫 토픽의 P0 상향과 검색 세부 방식, 일부 공개 자원의 오류 응답 등은 추가 합의가 필요하다.
- 문서상 정책 정리는 진행됐지만 실제 백엔드 구현과 동시 요청·DB 연동 검증은 아직 수행하지 못했다.

## Try

- 미정 사항을 담당자와 함께 검토하고, 확정 정책과 제안이 문서에서 혼동되지 않도록 정리하겠다.
- 탐사·프론트 담당자와 공개 필드, 별 목록·성과 요약, 그래프 상태·오류 계약을 교차 검토하겠다.
- 남은 수정분을 검증한 뒤 커밋하고, 환경설정과 기능 구현을 후속 Jira Task로 연결하겠다.
