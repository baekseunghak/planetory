## Problem

- 데모용 요소를 없애는 것만으로는 실제 서비스처럼 느껴지지 않았다. 화면에 정보가 있어도 사용자의 다음 행동이 명확하지 않거나 메뉴가 시각화를 가리면 사용 경험이 부족했다.
- 원하는 디자인을 말로만 설명하기 어려웠다. 실제 참고 화면과 시안을 비교하면서 메뉴·텍스트·천체 표현을 여러 차례 조정해야 했다.
- 현재 가상 데이터로 검증한 화면과 실제 백엔드 연결 완료는 다르다. 최신 API 문서와 현재 구현 사이에 별 배치 방식과 응답 구조 등 추가로 맞춰야 할 부분이 남아 있다.
- 자체 뷰어의 행성 표면·색·거리·궤도는 개념 표현이다. 실제 관측 정보와 시각적 연출을 구분해야 하며, 현재 테스트만으로 운영 환경의 렌더링 성능까지 보장할 수는 없다.
