## Keep

- 홀로그램 대시보드의 실제 데이터 조작·기록 복원을 검증하고, 기존 코드와 데이터를 보존하면서 임시 브랜치와 작업 폴더를 정리했다.

- 탐사 API 명세를 실제 화면 흐름과 대조해 잔차 단계 제출·주기 선택·요청 복구 등 구현 전에 해결할 충돌을 정리했다.

## Problem

- API 명세에 다음 잔차 단계의 제출을 막을 수 있는 조건과 주기·위상 검증 규칙의 충돌이 남아 있다.
- 일부 티켓에 독립적인 기능이 함께 묶여 있고, 담당 귀속과 선행 참조가 맞지 않아 구현 단위로 다시 나눌 필요가 있었다.
- 프로토타입 검증은 마쳤지만 최종 화면 채택과 실제 API 연동은 아직 남아 있다. 공개 그래프 권한처럼 다른 담당자와 먼저 맞춰야 하는 계약도 있다.

## Try

- 단계 전환·주기 선택·위상 폭·잔차 요청 복구 규칙을 백엔드 담당자와 먼저 맞추고, 같은 요청·응답 예제로 검증한다.
- 검토한 티켓 분할안을 팀과 확인하고, 바로 시작할 작업과 계약 합의를 기다릴 작업을 구분해 Jira에 반영한다.
- 최종 분석 화면 배치를 정한 뒤 첫 번째 튜토리얼의 안내·분석·제출·다음 단계 이동을 하나의 흐름으로 연결한다.
