## Problem

- 개별 티켓에 통합·배포 검증이 중복되어 있어, 기능이 구현돼도 계속 진행 중으로 남았다. 실제로 부족한 기능과 외부 환경을 기다리는 일을 구분하기 어려웠다.
- 닉네임은 서버에서 이미 자동 생성하고 있었지만, 티켓에 최초 입력 문구가 남아 있어 불필요한 완료 대기가 발생했다.
- 후속 브랜치가 앞선 작업을 포함하면서, 어느 MR부터 병합해야 하는지와 최신 변경이 어디까지 반영됐는지 관리가 복잡해졌다.
