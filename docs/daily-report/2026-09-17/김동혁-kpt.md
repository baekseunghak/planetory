## Problem

- 처음에는 JournalNode RPC 포트 8485만 확인해 Standby가 edit log를 읽을 때 사용하는 HTTP 8480 경로를 놓쳤다.
- 로그 검사에서 관리자 셸의 와일드카드 확장 실패를 숨겨 실제 오류가 있어도 0건으로 판정할 수 있었다.
- 서비스가 실행 중이고 기본 읽기·쓰기가 된다는 사실만으로 모든 장애 대체 경로가 정상이라고 판단하기 어려웠다.

## Try

- 분산 시스템 포트는 서비스별 목록이 아니라 실제 호출 주체에서 대상 endpoint까지의 연결 행렬로 검증한다.
