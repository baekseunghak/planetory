# 2026-09-07 KPT

## Keep

- 요구사항 명세서 v0.9를 기준으로 회원·커뮤니티·통계 백엔드의 누락 조건과 정책 충돌을 분석했다.
- 담당 범위를 21개 기능으로 나누고, 구현 계획·우선순위·결정 상태·남은 작업을 주제별 표와 상세 설명으로 문서화했다.
- 초기 다중 제공자 연결 제외, 인증·권한 오류 처리, 탈퇴와 작성 요청의 동시 처리 기준을 정리하고 결정 이력을 남겼다.

## Problem

- 판단 분포의 최신 판단 반영 기준과 통계 산식, 분석글 게시·성과 인정 시점에 모호하거나 충돌하는 조건이 남아 있다.
- 회원 정보와 DB 스키마, 탐사 성과와 커뮤니티 사이의 처리 경계는 담당자 간 협의가 필요하다.
- 로그인 유지·활동 기반 세션 갱신, 탈퇴 후 데이터 보관·공개 범위는 아직 확정하지 못했다.
