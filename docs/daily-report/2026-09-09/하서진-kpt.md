# 2026-09-09 KPT

## Keep

- 기존 화면이 마음에 들었기 때문에 원본을 보존하고 복제본에서 새로운 표현을 시도했다.
- 실제 참고 서비스를 보면서 원하는 모습을 구체적으로 설명했고, AI와 협업해 별 10만 개가 구름처럼 보이는 화면을 구현했다.
- 이미지뿐 아니라 확대·축소·회전·별 선택을 직접 확인하고, 빌드와 브라우저 테스트 8개, 저장 테스트 3개로 동작을 검증했다.

## Problem

- 별의 개수를 늘리는 것만으로는 원하는 별구름 느낌이 나오지 않았다. 별의 크기와 밀도, 빛 번짐, 나선 팔의 분포를 함께 조절해야 했다.
- 확대 범위를 크게 넓히자 작은 위치 오차가 커지는 문제가 나타났고, 그래픽 복구와 로컬 데이터 저장 과정에서도 오류가 발견됐다.
- 보기 좋은 첫 화면과 안정적인 서비스 동작을 따로 확인할 필요가 있었다.

## Try

- 기존 은하형과 새 별구름형을 팀원들에게 함께 보여주고, 시각적 매력뿐 아니라 별 선택의 편의성과 정보 가독성을 비교해보겠다.
- 시연용으로 추가한 표현과 실제 서비스에 적용할 기능을 구분하고, 명세와 달라지는 부분을 합의하겠다.
- AI가 구현한 코드 중 별 배치·빛 표현·확대 중심 계산부터 하나씩 이해해보겠다.
