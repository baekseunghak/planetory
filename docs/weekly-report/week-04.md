## 4. 주간 회고

### Keep

- 요구사항·상태표·와이어프레임·ERD를 교차 검토하면서 구현 전에 충돌을 발견하고 수정했다.
- 실제 관측 데이터와 브라우저 조작으로 PoC를 검증하고, 실행 방법과 검증 자료를 함께 남겼다.
- 전처리 실험에서 신호 보존 손실을 수치로 확인하고, AI 점수를 행성 확률로 해석하던 오류를 바로잡았다.
- 클라우드 계정 생성이 막힌 상황에서도 GCP 대안과 자동화 스크립트를 준비해 후속 작업을 진행했다.
- 티켓을 담당자별로 검토하면서 완료 조건·선행 관계·협의 대상을 구체화했다.

### Problem

- 같은 정책이 여러 문서에 반복되어 일부만 수정되거나 이전 규칙이 남는 일이 반복됐다.
- 데이터 소유권, 공개 권한, 성과 처리와 계산 책임처럼 여러 파트가 연결되는 경계의 합의가 늦었다.
- 시연용 동작과 운영 정책의 차이로 화면·Mock·API를 다시 맞추는 작업이 발생했다.
- 전처리 기본값, Gold 용량, 대규모 렌더링 및 분산 처리 성능은 추가 실측이 필요하다.
- 설계와 티켓 정리는 진행됐지만 실제 서버·DB·분산 환경을 연결한 전체 흐름 검증은 남아 있다.

### Try

- 공통 계약은 담당자와 결정 상태를 명시하고, 변경 시 관련 문서·예제·검증 조건을 함께 갱신한다.
- 최소 흐름을 먼저 연결한다. 데이터는 한 Sector 처리부터, 서비스는 별 하나의 분석·제출·결과·지도 복귀부터 검증한다.
- 티켓은 독립적으로 검토할 수 있는 결과 단위로 나누고, 각 기능에 테스트·문서·실제 연동 완료 조건을 포함한다.
- PoC 검증 결과와 운영 환경 검증 결과를 구분해 기록한다.

## 5. 다음 주 우선 과제

1. **API·담당 경계 합의**
   - 단계 전환, 위상 선택 범위, 잔차 요청 복구, 공개 그래프 권한과 성과 처리 계약을 정리한다.
   - 지도·분석·튜토리얼의 진입·복귀 정보와 후속 행동을 맞춘다.

2. **프론트 구현 기준 확정**
   - 분석 시안과 지도 표현을 팀에서 검토한다.
   - 합의한 API 기준으로 Mock을 갱신하고 첫 튜토리얼 흐름부터 연결한다.

3. **과학 처리 기준 검증**
   - 전처리 추가 설정을 실행하고 결과를 기록한다.
   - BLS 회수율과 신호 보존을 함께 평가해 기본값 결정 근거를 마련한다.

4. **분산 환경 통합 검증**
   - 사설 IP·호스트명 통신, HDFS 저장·복구, Spark on YARN을 순서대로 확인한다.
   - 소규모 데이터로 처리 시간·저장 용량·Gold 공개 과정을 측정한다.

5. **티켓 정리 및 착수 순서 확정**
   - 담당자별 분할안을 검토하고 중복·누락·잘못된 선행 참조를 정리한다.
   - 바로 착수할 작업과 계약·실험 결과를 기다릴 작업을 구분한다.
