- 결정·근거: 설치 전 점검에서 unit·18080 listener·`/spark-history`가 없고 고정 Spark image가 있으며, 기존 serve는 443 → `127.0.0.1:8081` 하나임을 확인했다. 첫 실행에서 Java가 `127.0.0.1` bind를 IPv4 매핑 표기 `[::ffff:127.0.0.1]:18080`으로 보고해 안전장치가 서비스를 끄고 serve 설정 전에 중단했다. 이 표기는 loopback 전용이므로 허용하도록 고치고 unit 내용은 바꾸지 않은 채 재실행했다.
- 검증: unit enabled·active, Java listener `[::ffff:127.0.0.1]:18080` 단독(테일넷 주소는 `tailscaled`), `serve status`에 18080과 기존 443 공존, PC에서 `http://node-1:18080` 200·443 200, `/api/v1/applications` 응답 `[]`, 컨테이너 메모리 약 337 MiB.
- 관련 문서: [인프라 안내](../../../infra/distributed-system/README.md), [78 인계](../../project/s15p21c206-78-handoff.md)
