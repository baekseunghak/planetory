- 수정자: 김동혁 (Claude 보조)

- 변경 범위: `contracts/derived-compute/` README·예제·검증기, `docs/architecture/online-derived-compute.md`
- 목적: Worker 구현 전에 계약의 빈 곳(빈 제거 조합, 주기도 설정, 실행 환경 기록, 주기도·자원 오류)을 메운다.

- 검증: `node contracts/derived-compute/validate.cjs` 통과(정상 3, 요청 오류 7, 오류 응답 2, timeout 1). Python JSON 왕복 통과. 빈 제거의 flux를 바꾸면 실패하는 것을 확인했다.
