## [S15P21C206-266] 요청된 확정 행성 NASA 조회·저장 경계

- 담당: 서비스 백엔드
- 유형: 데이터 | API 내부 계약 | 운영
- 상태: 구현 완료·격리 검증 완료. 공유/운영 DB 적용과 회원 화면 연결은 미실행
- 변경 범위: `V25__nasa_planet_info.sql`, 백엔드 NASA 조회·정규화·저장, [ERD](../../architecture/database-erd.md), [개발 계약](../../development/nasa-planet-info-266.md), [운영 가이드](../../operations/nasa-planet-info-runbook.md)
- 목적: 실제 요청된 확정 후보의 NASA PS 기본 해만 보관해 반복 호출을 줄이고, 외부 장애·식별 불명확성을 내부 확정 판정과 분리한다.
- 결정: 사용자 승인으로 기존 HOME-05의 **회원 본인이 수치 매칭한 행성만 표시**한다. 정상 7일·빈 결과/식별 불명확 1일 재확인, 일시 장애 중 이전 정상 자료 표시, 자동 삭제 없음. NASA 전체 카탈로그는 별 상세 목록의 원천이 아니다.
- 보류: 267의 설명 생성 모델·키·설명 저장, 268의 공개 요청/응답·화면 인수. Gold에 검증된 `archive` 식별 참조가 없는 후보의 연결은 추측하지 않는다. 운영 보관량·성능 실측과 공식 호출량 상한 확인도 남았다.
- 구현: 고정 NASA TAP 호스트·PS 기본 해·상태/오차/상하한/출처 정규화, 요청 후보당 한 행, 변경 해시, 후보별 DB 임대·시도 순번, 프로세스별 동시 2건/제한 재시도. 외부 HTTPS 중 DB 트랜잭션을 유지하지 않는다.
- 검증: 일회용 PostgreSQL의 V1~V25 적용과 로컬 HTTP fixture·권한 5개 사례(복수 행성·미매칭/모호함·null/단위/오차·빈 결과·429/5xx/timeout·동시 저장·오래된 응답·원본 변경/재사용) 통과. 실제 NASA TAP의 `TIC 150428135` 소량 읽기에서 기본 해 4행/3169 UTF-8 바이트를 확인했다. 이는 운영 배포·실제 회원 경로 인수가 아니다.
