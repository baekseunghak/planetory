## [S15P21C206-170] 검색 계약 검증기·문서 리뷰 보완

- 수정자: 백승학
- 유형: API·오류 정정
- 상태: 표본 검증 완료·교차 검토 대기
- 변경 범위: 기능 분석 README의 P0 도입문, 검색 표본·검증기·인계 문서
- 목적: 미정 입력을 임의의 API 정책으로 확정하지 않고 실행 검증 범위를 정확히 전달한다.
- 결정·근거: 빈 필터·미지원 입력은 API 코드가 아닌 UNSPECIFIED로 분리한다. 시각은 Date.parse와 숫자 ID로 비교하며 밀리초 정밀도 한계를 명시한다. 합성 본문 편향과 미검증 size 경계를 기록하고 프론트 readiness 문서 두 경로를 후속 작업에 명시한다. 기존 결정 이력과 SQL은 변경하지 않는다.
- 검증: 검색 30·페이지 1·핫 토픽 4·Unicode 2·미정 입력 11·시각 정렬 3건 통과. 공통 입력 30건의 프론트 비교와 기존 검색 단위 5건 통과. 루트 --frontend 실행의 안내·종료 코드 1 확인. 문서 상대 링크·git diff --check 통과. SQL 변경이 없어 PostgreSQL 재실행은 생략했다.
