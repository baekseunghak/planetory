## [S15P21C206-262] 옛 배포 버튼 시험: Play는 막히고 Retry는 막히지 않는다

- 수정자: 김동혁(Claude Code 보조)
- 유형: 운영 | 오류 정정
- 상태: 검증 완료
- 변경 범위: [CI/CD](../../operations/cicd.md) 「옛 버튼」 문단, [서비스 배포 현재 상태](../../project/service-deploy-status.md)
- 목적: 261이 넘긴 "옛 파이프라인 배포 job을 GitLab이 막는가"를 운영에서 확인하고 정본의 틀린 설명을 고친다.
- 결정·근거:
  - 한 번도 실행하지 않은 옛 manual job의 Play는 403으로 막혔다(파이프라인 `222890` `deploy:backend:ec2-a`, 더 새 `222918` 배포 뒤). 261이 막으려던 경우는 동작한다.
  - 옛 job의 Retry는 막히지 않는다. `ci_forward_deployment_rollback_allowed: true`에서는 예전에 성공했든 아니든 Retry가 롤백으로 허용된다. 정본은 "예전에 성공한 job의 재실행만"이라고 잘못 적고 있었다.
  - 시험으로 옛 Frontend `e9835da5`가 약 1분(01:18:58~01:19:45 KST) 운영에 올라갔다. `222444` 성공 job Retry로 `a8fb6667`에 되돌렸고 화면 번들이 시험 전과 같음을 확인했다.
  - Retry까지 막을지(`ci_forward_deployment_rollback_allowed` 끄기)는 버튼 되돌리기도 함께 막으므로 정하지 않았다.
- 검증: 배포 기록 21716(시험)·21717(되돌리기), Play 403 뒤 job `manual` 유지, 운영 Backend `6d1926d5` 불변
- 관련 문서: [CI/CD](../../operations/cicd.md), MR !221
- 후속 작업: Retry 보호 여부 결정
