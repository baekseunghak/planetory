- 수정자: Codex
- 유형: 파이프라인 설계·구현
- 상태: 오프라인 코드·단위 테스트 완료, 운영 배포·실제 DAG 실행 전
- 변경 범위: TESS 4단계 DAG, Raw checksum 기반 cached 감사·Worker 병렬 cleanup, Bronze 명시 Raw release·계보 검사, 정본 문서
- 결정·근거: 기존 다운로드/HDFS/Bronze 제어기를 재사용해 4개 DAG를 Sector 인자로 연결한다. Raw 최초 Commit의 상세 검증은 유지하고, 삭제 전 cached final에는 업로드 시 확정한 manifest HDFS checksum을 비교한다. 구형 marker는 상세 감사로 fallback하며 삭제 직전 파일별 SHA-256 대조를 유지한다. 새 DAG는 기본 일시정지로 배포·자동 실행과 분리한다.
- 검증: Airflow 계약 5개, HDFS 28개, Bronze 17개 오프라인 테스트. Airflow 실환경 import·단계 트리거와 신규 Sector 실제 처리·성능은 미검증이다.
- 관련 문서: [단계별 DAG 계약](../../../distributed-system/airflow/dags/README.md), [HDFS 적재](../../../distributed-system/ingestion/hdfs/README.md), [Bronze](../../../distributed-system/spark/README.md), [Jira](https://ssafy.atlassian.net/browse/S15P21C206-252)
- 후속 작업: Jira의 기존 단일 DAG·1~13 완료 조건을 최신 4단계 DAG·상한 70 목표와 정합화한다. 원천 발견·HDFS coverage 일반화·영속 중지/재개·운영 용량 게이트를 구현하고 실제 import·장애·성능을 검증한다.
