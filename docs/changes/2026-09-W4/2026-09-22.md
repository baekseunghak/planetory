# 2026-09-22 주요 변경

## [S15P21C206-234] 로그아웃 CSRF 면제 제거

- 수정 주체: 서비스 백엔드 인증 작업
- 유형: API · 오류 정정
- 상태: 구현 완료, 격리 검증 완료
- 변경 범위: SecurityConfig, AuthIntegrationTest, 프론트 인증 회귀, 회원·API·OAuth 정본
- 목적: 세션 부재를 근거로 로그아웃의 CSRF 검사를 건너뛰지 않는다.
- 결정·근거: 사용자 승인 2026-09-22. 로그인 여부와 관계없이 현재 세션의 유효 토큰은 204, 토큰 없음·오류·이전 세션 토큰은 403이다. 반복 요청은 새 CSRF 조회 후 실행한다. Redis 전환은 237의 별도 범위다.
- 검증: 일회용 PostgreSQL에서 백엔드 전체 build 및 607개 테스트(인증 27개 포함) 통과. 실제 HTTP에서 토큰 발급·쿠키 왕복·반복 로그아웃을 검증했다. 프론트 요청 단위 10개·Chrome 인증 10개 통과. 브라우저는 개발용 쿠키 CSRF 서버 기준이며 실제 제공자·운영 프록시 인수와 구분한다. 번들 Chromium 실행 파일 부재로 Chrome을 사용했다.
- 관련 문서: [서비스 API 3.3절](../../../apps/backend/docs/service-api-spec.md#33-로그아웃), [회원 F02](../../development/service-backend/account.md#f02), [OAuth 설정](../../../apps/backend/docs/oauth-setup.md), [Jira 234](https://ssafy.atlassian.net/browse/S15P21C206-234)
- 후속 작업: 237에서 Redis 적용 후 같은 CSRF 계약을 회귀 검증한다. 공유·운영 DB 적용, 배포, commit·push·MR·Jira 변경은 수행하지 않았다.
