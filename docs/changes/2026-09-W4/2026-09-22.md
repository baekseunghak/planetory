## [S15P21C206-84] MR 단계 마이그레이션 검사가 실행되지 않던 결함 수정

- 수정자: 김동혁, Claude
- 유형: 운영
- 상태: 수정·MR 파이프라인 통과 확인
- 변경 범위: `.gitlab/ci/apps/backend.yml`, `docs/project/service-deploy-status.md`
- 목적: MR !161이 `backend:schema` 하나 때문에 계속 실패하던 것을 없애고, 마이그레이션 검사가 실제로 동작하게 한다.
- 결정·근거: `alpine/git` 이미지의 `ENTRYPOINT`가 `["git"]`이라 Runner가 붙이는 셸이 `git sh -c ...`로 조립되고 `git: 'sh' is not a git command`로 죽었다. 스크립트가 한 줄도 실행되지 않아 검사가 있으나 마나였다. 이미지를 바꾸는 대신 `entrypoint: [""]`로 비웠다. 타깃 브랜치의 마이그레이션 번호를 대조해야 하므로 git이 있는 이미지는 그대로 필요하다. 같은 함정이 있는 이미지가 더 있는지 전체 job의 image 지정을 훑었고 이것뿐이다.
- 검증: 서버에서 `docker inspect`로 `Entrypoint=["git"]`을 확인하고, 셸을 붙이면 실패하고 entrypoint를 비우면 `git version 2.45.2`가 나오는 것을 재현했다. 수정 후 MR 파이프라인이 통과했고 `backend:schema` 로그에서 타깃 브랜치를 가져와 develop의 최대 버전 `V19`와 대조한 뒤 「버전 선점 검사 통과」·「마이그레이션 검사 통과」가 찍혔다. `glab ci lint` 통과.
- 한계: 선점 충돌이 실제로 발생한 상황에서 이 검사가 MR을 막는 것은 아직 관찰하지 않았다. 로컬 재현으로만 확인했다.
- 관련 문서: [서비스 배포 현재 상태](../../project/service-deploy-status.md), [CI/CD](../../operations/cicd.md)
- 후속 작업: 없음. MR !161 리뷰로 이어진다.
