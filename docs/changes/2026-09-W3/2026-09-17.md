# 2026-09-17 주요 변경

## [S15P21C206-185] 위상 핸들 키보드 이동 간격 결정

- 수정자: 백지웅 요청으로 Codex 작성
- 유형: 요구사항
- 상태: 사용자 채택·프론트 구현
- 변경 범위: 분석 프론트 상세 명세 §6.4·Q03, 위상 선택 UI
- 목적: 숫자 직접 입력 없이도 확대 수준에 맞게 구간을 조정한다.
- 결정·근거: 사용자 답변으로 방향키는 현재 보기 위상 폭의 1/1000, Shift는 10배를 적용한다. 포인터 좌표는 이 간격으로 반올림하지 않는다. 키보드 이동은 서버 선택 규칙이나 수치 허용 오차를 바꾸지 않는다.
- 검증: 단위 115개·빌드와 Chrome 화면 검사. 실행 범위·결과는 [개발 안내](../../../apps/frontend/docs/phase-selection.md#검증과-미확정-경계)에 기록한다.
- 관련 문서: [상세 명세](../../development/analysis-frontend-spec.md#64-조작접근성과-깜빡임-방지), [Jira #185](https://ssafy.atlassian.net/browse/S15P21C206-185)
- 후속 작업: 시간 곡선 예상 띠·파생값 표시·판단·제출 연결, 서버 공통 fixture 인수. DB·API 필드 변경은 없다.

- 수정자: 백지웅 요청으로 Codex 작성

- 상태: 사용자 채택·프론트 구현

- 목적: 이전 목업에서 합의한 조작을 실제 기능에 반영한다.
- 결정·근거: 기존 `analysis-lab`의 기본 드래그 선택·Shift+드래그 이동 결정을 사용자가 재확인했다. 2단계 구현에 잘못 추가한 그리기 모드 버튼을 제거하고 해당 동작을 상세 명세의 조작 기준으로 옮긴다. 32배 상한과 핸들 방향키 간격은 유지한다.
- 검증: [개발 안내](../../../apps/frontend/docs/phase-selection.md#검증과-미확정-경계)에 실제 실행 결과를 기록한다.
- 관련 문서: [기존 사용자 피드백 기록](../../../experiments/analysis-lab/README.md), [상세 명세](../../development/analysis-frontend-spec.md#64-조작접근성과-깜빡임-방지)

## [S15P21C206-185] 선택 상태 공유와 시간 곡선 미리보기 연결

- 수정자: 백지웅 요청으로 Codex 작성
- 유형: 아키텍처
- 상태: 구현·로컬 검증 완료
- 변경 범위: 프론트 AnalysisSession, 위상 편집, 시간 미리보기·예상 띠
- 목적: 선택값과 파생값을 같은 상태에서 갱신하고 재접기 실패·취소 시 함께 복원한다.
- 결정·근거: 곡선 문맥마다 접기 세션과 위상 초안을 공유한다. 예상 띠는 실제 BTJD로 계산하고 세그먼트별 표시 좌표에 투영한다. 독립 Canvas로 띠를 그려 핸들 이동이 관측점 전체 재그리기를 유발하지 않게 한다.
- 검증: 단위 120개·빌드, Chrome 통합 40개 후 미리보기 4개 재검증(취소 복구 1개 추가). 서버 대조·다른 브라우저는 미검증이다.
- 관련 문서: [개발 안내](../../../apps/frontend/docs/phase-selection.md#3단계-시간-미리보기와-예상-띠), [분석 명세](../../development/analysis-frontend-spec.md#62-위상-선택과-서버-파생값)
- 후속 작업: 4단계 판단·근거·메모·제출 초안, 실제 API 인수. DB·API 계약 변경은 없다.
