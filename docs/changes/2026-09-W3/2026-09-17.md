- 미확정: 메모 2,000 코드포인트는 탐사 API §6.1/D-12의 초안을 임시 UI 상한으로 사용했으며 확정 계약이나 사용자 승인으로 간주하지 않는다. 실제 제출·서버 검증·fieldErrors 연결은 #187에 남는다.

- 관련 문서: [개발 안내](../../../apps/frontend/docs/phase-selection.md#4단계-판단과-제출값-확인), [분석 단계·복구 명세](../../development/analysis-frontend-spec.md#5-입력-단계와-초기화복구)
