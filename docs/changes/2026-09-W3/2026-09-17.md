- 데이터 손실 경계: Gold 카탈로그는 GCP HDFS의 PublicationBundle이 RF2로 있어 재게시로 복구 가능하다. 회원·제출·분석 히스토리·커뮤니티 데이터는 사본이 없어 복구 수단이 0개이며 PoC 범위에서 수용한다. 가장 싼 완화는 EBS 스냅샷이고 도입 여부는 미결이다.
- 검증(실행한 것): 문서 상대 링크 전수 존재 확인, 잔존 문자열 grep은 각 담당 파일 범위에서만 수행했고 저장소 전수 확인은 하지 않았다. 전수 검증에서 발견된 잔존 참조는 같은 날 별도로 정정했다
- 검증(실행하지 않은 것): 코드 테스트·빌드는 실행하지 않았다(문서·Jira 변경만이라 대상 없음). 단일 connector의 지속 처리량·재연결·무료 플랜 제약은 실측하지 않았고 84에서 확정한다. Cloudflare proxied 라운드로빈의 실제 교대 동작은 과제 전제로 받은 사실이며 실측하지 않았다. `docker compose`와 CI job의 실제 동작도 실행해 확인하지 않았다. commit·push하지 않았다.
