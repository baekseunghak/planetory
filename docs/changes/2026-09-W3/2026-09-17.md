# 2026-09-17 주요 변경

## [S15P21C206-185] 위상 핸들 키보드 이동 간격 결정

- 수정자: 백지웅 요청으로 Codex 작성
- 유형: 요구사항
- 상태: 사용자 채택·프론트 구현
- 변경 범위: 분석 프론트 상세 명세 §6.4·Q03, 위상 선택 UI
- 목적: 숫자 직접 입력 없이도 확대 수준에 맞게 구간을 조정한다.
- 결정·근거: 사용자 답변으로 방향키는 현재 보기 위상 폭의 1/1000, Shift는 10배를 적용한다. 포인터 좌표는 이 간격으로 반올림하지 않는다. 키보드 이동은 서버 선택 규칙이나 수치 허용 오차를 바꾸지 않는다.
- 검증: 단위 115개·빌드와 Chrome 화면 검사. 실행 범위·결과는 [개발 안내](../../../apps/frontend/docs/phase-selection.md#검증과-미확정-경계)에 기록한다.
- 관련 문서: [상세 명세](../../development/analysis-frontend-spec.md#64-조작접근성과-깜빡임-방지), [Jira #185](https://ssafy.atlassian.net/browse/S15P21C206-185)
- 후속 작업: 시간 곡선 예상 띠·파생값 표시·판단·제출 연결, 서버 공통 fixture 인수. DB·API 필드 변경은 없다.

## [S15P21C206-185] 기본 드래그 선택·Shift 이동 복원

- 수정자: 백지웅 요청으로 Codex 작성

- 관련 문서: [기존 사용자 피드백 기록](../../../experiments/analysis-lab/README.md), [상세 명세](../../development/analysis-frontend-spec.md#64-조작접근성과-깜빡임-방지)
