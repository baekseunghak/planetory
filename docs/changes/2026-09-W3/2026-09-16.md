## [S15P21C206-68] Gold 게시 계약과 합성 fixture 정합화

- 수정자: Codex (사용자 요청에 따른 계약 정리)
- 유형: 데이터 · API · 요구사항
- 상태: 검증 완료
- 변경 범위: Gold 계약 README·정상/오류 fixture·검증기, 탐사 API Bundle 버전, current 판 주석·인수 조건
- 목적: Publisher의 PostgreSQL 행, Backend 읽기 모델과 Frontend 응답이 같은 TIC·Bundle의 필드·단위를 해석하도록 한 예제로 고정한다.
- 결정·근거: Gold는 PostgreSQL 배열과 manifest가 정본이며 품질 마스크는 배치 내부에서만 소비한다. API 식별자는 `b-<id>`·`seg-<id>`, Bundle 버전은 DB부터 API까지 문자열로 맞추고, 진행 중 분석은 과거 판에 고정하지 않고 current를 대조한다. fixture의 box 모델과 checksum 방식은 합성 검사용이며 D06·D09의 과학·언어 간 직렬화 결정을 대신하지 않는다.
- 검증: `node contracts/gold/validate.cjs`에서 정상 1건·오류 5건 PASS, 기존 탐사 계약 14건·검토 시나리오 6건 PASS, `git diff --check` PASS. 샌드박스 JDK의 classpath 접근 오류를 분리한 뒤 로컬 PostgreSQL 컨테이너에서 Gold 저장소·스키마·역할 권한 테스트 20건이 모두 통과했다.
- 관련 문서: [Gold 게시 계약](../../../contracts/gold/README.md), [탐사 API](../../../apps/backend/docs/exploration-api-spec.md), [인수 조건](../../requirements/planetory-acceptance-criteria.md), [Jira S15P21C206-68](https://ssafy.atlassian.net/browse/S15P21C206-68)
- 후속 작업: Jira에 요청한 데이터·Backend·Frontend 담당자의 승인·수정 의견을 기록하고, D06 `transit_model`과 D09 운영 checksum 계약을 별도 완료한다.
