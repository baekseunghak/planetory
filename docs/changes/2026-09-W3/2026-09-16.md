- 결정·근거: `(tic_id, bundle_version)`을 DB 유일 재시도 키로 사용하고 DB 생성 `id`는 결과로만 취급한다. `bundle_version`은 곡선 원천·외부 참조 snapshot·세그먼트 자연 키·계산 버전의 결정적 SHA-256이다. 외부 snapshot이 바뀌면 새 판을 만들며, 동일성은 생성 id를 제외한 자연 키·checksum·계산 버전·Bundle 수치 메타데이터로 비교한다. 부분 유일 인덱스의 즉시 검사에 맞춰 기존 current를 먼저 archived로 바꾼 뒤 신규 staging을 current로 올린다. 검증 실패와 일시 rollback을 구분하고 archived 판의 늦은 재시도는 현재 판을 되돌리지 않는다.
- 검증: `node contracts/gold/validate.cjs`에서 게시 시나리오 6건, 기존 Gold 정상 1건·오류 5건이 통과했다. 기존 탐사 계약 14건·검토 시나리오 6건, Gold Gradle 테스트 20건, 상대 링크와 `git diff --check`도 통과했다. 실제 Publisher·PostgreSQL 동시 실행과 `UNIQUE(tic_id, bundle_version)` migration은 86·87번 범위다.
- 관련 문서: [데이터 관리](../../data/data-guidelines.md), [Gold 게시 계약](../../../contracts/gold/README.md), [DB ERD v1.6](../../architecture/database-erd.md), [Jira S15P21C206-69](https://ssafy.atlassian.net/browse/S15P21C206-69)
- 후속 작업: Data 검토는 승인됐다. Backend가 전환 순서와 외부 snapshot 포함 규칙을 재검토한 뒤 86·87번 구현에 인계한다. 후보·AI checksum의 DB 생성 id 제외는 117번에 인계한다.
