## [S15P21C206-227] 개별 별 은하 표현과 페이지 조회 계약

- 수정자: 하서진의 요청으로 Codex 작성
- 유형: 요구사항·API·문서 / 상태: 제안
- 변경 범위: SRS v1.3, 인수 조건·결정 등록부·개정 이력, 표현 계약, 탐사 API Draft 0.4, ERD, 상태표, 와이어프레임, 역할 문서와 안내

- 결정·근거: 같은 원본 1,000개 별과 카메라로 비교한 사용자 선택을 반영한다. 군집 기술 일반의 한계나 10만 별 성능 통과를 주장하지 않는다. 저장 은하 좌표·가시 범위 조회는 유지하며 군집/고정 개수 상한 대신 개별 별 페이지·표현 상세도를 사용한다.

- 검증: JSON 예시 파싱, AT ID 중복, 동일 TIC 좌표·페이지 수/범위, 상대 링크, diff 공백, 와이어프레임 JS 구문을 확인한다. 브라우저 렌더·실제 API/DB·10만 별 성능은 미검증이다.
- 관련 문서: [변경 검토 기록](../../development/sky-individual-stars-review.md), [표현 계약](../../development/sky-presentation-contract.md), [Jira 227](https://ssafy.atlassian.net/browse/S15P21C206-227)
