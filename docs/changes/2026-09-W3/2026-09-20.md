- 유형: 오류 정정

- 변경 범위: `experiments/tess-bench/uv.lock`의 astro-kernel 개발 의존성 메타데이터

- 결정·근거: 공용 astro-kernel에 이미 선언된 `jsonschema>=4.18,<5`를 lockfile에 반영했다. 오프라인 `uv lock`으로 갱신했으며 패키지 버전·실험 설정은 바뀌지 않았다.
- 검증: `uv sync --locked --offline --python 3.11` 성공, `uv run --locked --offline`으로 population·BLS 테스트 26개 통과. 기존 가상환경 직접 테스트만으로는 lockfile 정합성을 검증하지 못하므로 실행 경로까지 확인했다.
- 관련 문서: [실행 방법](../../../experiments/tess-bench/README.md)
- 후속 작업: 사용자 예비 실측
