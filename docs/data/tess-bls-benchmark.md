# BLS 탐색 격자·품질 게이트 벤치마크

작성일: 2026-09-16 / 담당: 윤성용 / Jira: `S15P21C206-110` (계획 ID D04) / 코드: `experiments/tess-bench/` (`bls`, `bls-gates` 명령, 설정 `configs/bls_settings_v1.json`) / 상태: 조정 단계(4별) 실행·분석 완료(5절), 평가 단계(5별)는 기록 예정, 채택 제안은 팀 리뷰 전

이 문서는 탐색용 BLS 의 주기 격자·지속시간 격자·목적함수와 품질 게이트(SDE·SNR·통과 횟수)를 같은 fixture 에서 비교해 DEC-03 채택 임계값 후보와 `bls_config_version` 을 제안하는 실험의 계획·규칙·결과를 기록한다.
근거는 [후보 검출 설계](tess-pipeline/candidate-detection.md) 5.6절(격자·게이트 제안)·5.7절(벤치마크 설계), 입력은 [TESS fixture 세트](tess-fixture-set.md) 의 9별과 주입 격자 1.1.0, 전처리는 [전처리 벤치마크](tess-preprocess-benchmark.md) 채택 잠정값 `biweight_1.0d` 다.
반복 제거·종료는 `S15P21C206-111`, 고조파 병합·후보 동일성은 `S15P21C206-112`, 운영 커널은 `S15P21C206-120`, 사전 선별 경로(5.7절 A/B/C)는 Jira 제외 범위라 다루지 않는다.

## 1. 질문

1. 어떤 주기 격자(선형 5천·2만·5만 / astropy 주파수 등간격)·지속시간 격자·목적함수가 심은 신호를 가장 잘 회수하면서 계산 시간이 감당되는가.
2. SDE·SNR·통과 횟수 문턱을 어디에 두면 신호 없는 곡선의 가짜 후보가 허용 범위에 들고 약한·장주기 신호를 잃지 않는가.
3. 회수한 후보의 주기·epoch·지속시간·깊이 오차는 얼마인가. 42 가 재지 못한 지속시간·epoch 보존을 여기서 기록한다. **이 결과로 42(D03) 의 보존 조건을 대체하는지는 팀 승인 사항**이며 미승인 시 원본 조건을 유지한다.

## 4. 저장하는 것과 판정 규칙

**상위 피크 5개**(상대 주기 차 2% 미만은 같은 봉우리): period, epoch, duration, depth, power, log_likelihood, **SDE**, **SNR**, PoC 식 SNR(대조용), 관측된 통과 회차 수, 통과 창 안 점 수, 전처리로 빠진 예상 통과 점 비율.

- **SDE 정의**: `(power[peak] − mean(power)) / std(power)`, 같은 곡선·설정의 주기도 전체에서. likelihood 와 snr 목적함수의 power 는 척도가 달라 설정 사이 SDE 값을 직접 비교하지 않고 설정 안에서 문턱을 고른다. std 가 0·비유한이면 NaN(퇴화 입력).
- **SNR 정의**: astropy `depth_snr = depth/depth_err`. 점 오차는 정제곡선 robust scatter(1.4826×MAD) 를 모든 점에 같은 값으로 준다. PoC 의 수동 SNR 은 별도 열이며 SDE 구현 근거가 아니다. `PDCSAP_FLUX_ERR` 사용은 5.6절 TBD.
- **매칭**(5.7절·SRS 5.1): 직접 = `|P_피크 − P_주입| × N_주입 ≤ D_주입/2` 이고 통과 창 중첩 ≥ 0.5. 중첩은 주입·피크 통과 창 교집합 점 수를 **두 창 집합 중 작은 쪽** 점 수로 나눈 값이다(2P alias 는 주입 창의 절반만, P/2 alias 는 전부 덮으므로 한쪽 기준이면 비대칭). alias = 피크 주기를 2배·절반으로 환산해 같은 규칙(`alias_half`·`alias_double`). 둘 다 아니면 `wrong`(가장 가까운 피크의 오차 기록), 피크가 없으면 `missed`. 직접이 alias 보다 우선, 같은 종류면 순위가 높은 피크.
- **원시 오차**는 판정과 무관하게 항상 저장: 주기 상대 오차, epoch 순환 오차(시간), 지속시간 비, 깊이 비, 창 중첩, 누적 오차/(D/2). 허용 오차를 바꿔도 재실행 없이 재판정할 수 있다.
- **탐색 범위**: 매칭 행마다 `in_search_range`(주입 주기가 그 설정의 상한 `period_max_days` 안인가)를 저장한다. 설정 비교와 게이트 회수율은 **범위 안 신호만** 쓴다. 범위 밖 신호(짧은 관측의 20일 주입)는 어느 격자도 못 찾으므로 격자 성능이 아니라 범위 규칙의 문제다.
- **게이트**(`bls-gates`, 오프라인): SNR ≥ {5,7,9,12}, SDE ≥ {6,8,10,12}, 통과 ≥ {2,3} 의 단독·조합마다 (1) 범위 안 주입 중 매칭 피크가 게이트를 통과한 비율, (2) 순수 잡음 곡선당 게이트 통과 피크 수(가짜), (3) 주입 없는 실제 곡선(realclean `none`)당 게이트 통과 피크 수(잔여) 를 낸다. 잔여는 미확인 신호일 수 있어 가짜로 단정하지 않지만, 잡음 곡선만으로 게이트를 고르면 실제 별의 계통 오차가 후보로 남는 것을 놓친다. 허용 목표는 팀 리뷰 전 TBD.

- **SNR 만으로는 부족하다.** SNR ≥ 7 은 잡음 곡선의 가짜 피크를 4별 모두 0 으로 만들지만, 실제 곡선의 잔여 피크 5개는 4별 모두 그대로 통과한다. 원인은 별마다 다르다: TOI-451 은 자전 변광이 2.7 d 부근 피크로 남고(SNR 17, SDE 3–4), π Men 은 산포가 매우 작아 통과 1회짜리 임의 피크가 SNR 194 로 나오며(SDE 1.5), TOI-270 은 SNR 7–8·SDE 3–5 의 약한 피크가 문턱에 걸린다. 셋 다 SDE 가 낮아 **SDE ≥ 6 을 더하면 세 별의 잔여가 0** 이 된다.
- **SDE ≥ 6 의 비용**은 범위 안 신호 105개 중 10개(TOI-270 1, TOI-451 2, π Men 7). π Men 손실이 큰 이유는 산포가 작은 별에서 SDE 분모(주기도 전체 std)가 계통 오차로 부풀어 진짜 신호의 SDE 도 낮게 나오기 때문이다. 이는 42/119 의 계통 오차 처리 몫이며 게이트로 풀 문제가 아니다.
- **WASP-62 잔여 5개는 게이트로 안 걸러진다.** 제거한 WASP-62 b(4.412 d) 자리에 SNR 50·SDE 31 피크가 남고 나머지 4개는 그 절반·2배·3배 주기다(2.206·8.823·13.236·1.47 d). 고정 box 모델로 나눈 뒤 진입·이탈 파형과 미세한 주기 차이가 남는 것으로, 111(반복 제거·종료)과 112(고조파 병합)에서 "제거한 후보의 주기와 그 고조파는 다음 반복에서 제외" 규칙이 필요하다는 근거다. 이 벤치마크 안에서는 실제 잔여로 기록만 한다.
- `objective_snr` 은 회수는 같지만 SDE ≥ 6 에서 회수가 0.69·0.50·0.45·0.21 로 떨어진다(likelihood 는 0.83·0.63·0.64·0.33). SNR 목적함수의 power 분포가 넓어 같은 문턱에서 진짜 신호도 잘린다.

## 6. 한계·후속

- 지속시간·epoch 오차는 "BLS 가 그 파라미터를 얼마나 맞히나" 이며 전처리의 파형 보존 전체를 증명하지 않는다.
- 조정 4별은 42 에서 이미 본 별이라 평가 단계 결과만 일반화 근거로 쓴다.
- 설정 채택은 42 확정 전처리로 재실행한 뒤 승인받는다(Jira 완료 조건).
- 조정 단계의 잡음·실제 `none` 곡선은 별당 1개라 가짜·잔여 수는 방향만 보여준다. 평가 단계에서 seed 3개로 늘리고, 허용 목표(곡선당 가짜 후보 수)는 DEC-01 무신호 비율과 함께 정한다.
- 5.1 표의 `bls-gates` 수치는 조정 run 의 `matches.csv` 에 `in_search_range` 열이 없던 시점의 것이라 `--baseline-days` 로 상한을 다시 계산했다. 평가 단계 run 부터는 열이 저장된다.
- WASP-62 의 제거 잔여(4.412 d 와 고조파)는 111·112 의 "제거 후보 주기·고조파 제외" 규칙 근거로 넘긴다. astro-kernel 고정 box 모델의 한계이며 여기서 모델을 바꾸지 않는다.
- **SNR 오차 산정(리뷰 지적).** 구현은 정제곡선 전역 robust scatter 하나를 모든 점에 같은 값으로 준다. 후보 검출 설계 5.6절이 비교하라고 한 두 선택지(원본 `PDCSAP_FLUX_ERR` / 국소 scatter) 어느 쪽도 아니다. π Men 의 SNR 194 임의 피크와 SDE 손실 7개는 저산포 별에서 전역 scatter 가 국소 조건을 반영하지 못할 때 나오는 모양이라, 42/119 계통 오차 몫으로만 돌리지 않고 평가 단계에서 세 방식을 비교한다(5.3절). 120 은 그 결과 뒤에 SNR 정의를 가져간다.
