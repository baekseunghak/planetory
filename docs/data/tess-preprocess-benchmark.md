# TESS 전처리·detrending 벤치마크

작성일: 2026-09-10, 1.1.0 결과 반영 2026-09-14 / 담당: 윤성용 / Jira: `S15P21C206-42` / 코드: `experiments/tess-bench/` / 상태: 설정 1.0.0·1.1.0 실행 완료, 결과·제안 기록 완료, 팀 리뷰 전

이 문서는 BLS 전 전처리 설정(품질 마스크, 구간 분리, detrending 방법·창, 실패 처리)을 고정 fixture 에서 비교해 서비스 기본값을 제안하는 실험의 계획과 결과를 기록한다. 근거는 [갭 분석](tess-pipeline/README.md) 5.2~5.5절(기존 코드 확인)·7.1절(비교 실험 계획), 입력은 [고정 fixture](tess-fixture-set.md) 다. BLS 설정은 바꾸지 않으며(후속 A Task), 여기 제안값은 팀 리뷰 전 제안이다.

## 1. 질문

BLS 에 넣기 전에 곡선을 어떻게 다듬어야 심은 통과 신호는 살고 잡음은 줄어드는가. 기존 PoC `pipeline.clean` 의 값(QUALITY==0, 공백 0.5일, Savitzky–Golay 2일, 위쪽 5σ, 최소 500점)은 근거 없이 넣은 기본값이라 이 실험으로 근거를 붙이거나 바꾼다.

## 2. 비교 설정 (`configs/preprocess_settings_v1.json`, 11개)

설정 파일은 1.1.0 이다. 1.0.0 의 11개는 그대로이고 가장자리 마스크 4개·2단계 3개가 추가되어 18개다. 5.1~5.3 절 결과는 1.0.0 의 11개로 실행한 것이며, 추가된 7개와 기준 재현은 5.4 절에 기록했다. 1.0.0 의 나머지 10개는 1.1.0 에서 다시 돌리지 않았다(코드 변경이 그 설정의 계산 경로를 건드리지 않고, 기준 설정이 동일하게 재현됐다).

비트마스크 175·7407 은 이번 실험에서 고정한 마스크 값이다. 출처 확인(2026-09-14, GitHub 소스 대조): lightkurve **v1.11.3** `TessQualityFlags` 의 `DEFAULT_BITMASK` = AttitudeTweak(1) | SafeMode(2) | CoarsePoint(4) | EarthPoint(8) | Desat(32) | ManualExclude(128) = 175, `HARD_BITMASK` = 175 | ApertureCosmic(64) | CollateralCosmic(1024) | Straylight(2048) | Straylight2(4096) = 7407 과 일치한다. **현재 lightkurve main 의 값은 다르다**: DEFAULT 에 Argabrightening(16)·ImpulsiveOutlier(512)·BadCalibrationExclude(16384) 가 추가되어 17087, HARD 는 24319 다. 따라서 175·7407 을 "현재 lightkurve 기본값" 으로 부르지 않는다. 비트 이름은 lightkurve 소스의 명명이며, TESS Science Data Products Description Document 의 QUALITY 표 원문과의 대조는 하지 않았다. 설정 파일 1.0.0/1.1.0 의 `description` 문구("공식 기본/강한 비트마스크")는 실행 당시 manifest 의 sha256 과 대응하므로 소급 수정하지 않고, 이 문장을 정본으로 둔다.

## 3. 입력과 지표

입력: fixture 격자 1.1.0 을 TOI-270 real 바탕곡선과 잡음 바탕곡선(seed 20260910)에 주입한 228개 신호(단일 108 + 다중 쌍 6, 바탕곡선 2종). 주입 목록은 `tess_fixture inject` 와 같은 규칙으로 만들어 같은 catalog 가 된다. 품질 마스크를 바꾸는 설정은 바탕곡선을 그 마스크로 다시 만들고 같은 t0 로 주입한다.

| 지표 | 계산 | 읽는 법 |
|---|---|---|
| 깊이 보존율 | 전처리 후 (통과 밖 중앙값 − 통과 구간 중앙값) ÷ 심은 깊이. **전처리 후 겉보기 깊이 비율**이다 | 1.0 보존. 0.5h·2h·8h 별로 나눠 봄. 1 을 넘을 수 있고 그 불확실성은 측정하지 않음(아래) |
| 통과 점 유지율 | 통과 구간 점 중 전처리 후 남은 비율. 분모는 품질·유한값 필터를 통과한 바탕곡선의 통과 구간 점 수(원본 FITS 전체 cadence 가 아님) | 가장자리 마스크·clipping 영향. 품질 마스크 차이는 `n_points_after_quality` 로 봄 |
| 잡음 (ppm) | 통과 밖 robust scatter | 낮을수록 좋음. 깊이 보존과 함께 |
| 경계 왜곡 | 구간 경계 ±0.5일 통과 밖 \|flux−1\| 중앙값 ÷ 잡음 | 순수 잡음이면 약 0.67(정규분포 median\|x\| = 0.674σ). 눈에 띄게 크면 경계 근처 추세 잔여·왜곡 |
| 실패 구간 | 곡선당 중앙값 대체·비정상 추세 구간 수 | 실패 처리가 사유와 함께 기록되는지 |
| 가장자리 제외 비율 | 마스크로 제외된 점 ÷ 전체 점 | `edge*` 설정에서만 0 이 아님. 통과 점 유지율과 함께 읽음 |

겹치는 다중 신호는 다른 신호의 알고 있는 모델로 나눠 대상 신호만 남긴 뒤 깊이를 잰다. BLS 회수율은 여기서 재지 않는다.

**깊이 지표의 한계.** real 바탕곡선에는 실제 별의 잔여 변동과 계통 오차가 남아 있고, 추세는 심은 신호와 바탕곡선을 함께 본 뒤 추정된다. 따라서 깊이 보존율은 detrending 이 통과를 깎은 양과 바탕곡선 잔여·공동 추세 추정의 영향을 완전히 분리하지 못한다. 잡음 바탕곡선(5.2)과의 비교가 그 영향을 어느 정도 보여 주지만 신호별 불확실성(오차 범위)은 측정하지 않았다. 1 을 넘는 값(예: 다중 신호 쌍의 1.06)도 같은 이유로 "과대 추정" 이라고 단정하지 않고 불확실성 미측정으로 둔다. 이번 Task 에서는 측정 알고리즘을 바꾸지 않고 이 한계를 명시하는 것으로 한다.

**biweight 구현 기록.** 이 벤치마크의 biweight 는 자체 구현이다. 초기값 중앙값, 척도 MAD(정규화 상수 없음), 절단 c = 6, 고정 3회 반복, MAD 가 0 이거나 가중치 합이 0 이면 현재 중심값 반환. 이동 창은 평가점 시각 ±창/2 를 `searchsorted` 로 잡고 구간 시작·끝에서는 창이 한쪽만 채워진 채 계산한다(패딩·반사 없음). 평가점은 10점(`biweight_stride`) 간격과 마지막 점이며 그 사이는 `np.interp` 선형 보간이다. astropy `biweight_location` 이나 wotan 의 구현과 초기값·반복 종료·척도 정의가 다를 수 있으므로 "표준 함수와 동일" 이라고 하지 않는다. SG 는 SciPy `savgol_filter`(2차, 창 점 수는 홀수·최소 11)다.

## 4. 실행

현재 설정 파일(1.1.0, 18개)로 별 하나를 전부 돌리는 명령. real 바탕곡선만이면 별당 약 15~20분(2단계 biweight 가 대부분).

```powershell
cd experiments/tess-bench
uv sync --locked
uv run python -m tess_bench preprocess --target toi270 --no-noise     # 설정 18개, real 바탕곡선
uv run python -m tess_bench preprocess --target toi270                # + 잡음 바탕곡선
```

산출물은 `results/bench/preprocess_v1-<ver>/<별>/run-*/summary.csv`(설정별 요약)와 `metrics.csv`(신호별), manifest 는 `results/manifests/`. Git 제외.

**이 문서의 결과가 나온 실행 기록.** 위 "전부" 명령과 다르므로 구분해 둔다.

## 6. 해석과 제안 (팀 리뷰 전)

**창 하한.** 창 ≤ 0.5일은 어느 방법이든 8h 통과를 60 % 이상 깎고, 저잡음 별에서는 biweight 가 통과를 거의 지운다(π Men 0.07). 창은 최소 1일(최대 통과 길이 8h 의 3배, DAT-02 하한)이어야 한다.

**창 상한.** 조용한 별에서는 창 2~3일까지 잡음 증가가 없지만, 활동성 별(TOI-451)에서는 2일 창이 잡음을 42 % 늘린다. 별의 변광 시간 규모보다 짧은 창이 필요하다.

**SG 대 biweight.** 1일·2일 창에서는 네 별 모두 biweight 의 8h 보존이 같은 창의 SG 보다 높다(1일 0.86~0.98 대 0.36~0.45). 0.5일 창에서는 π Men 에서 biweight 가 SG 보다 낮았다(0.07 대 0.15). 잡음은 biweight 1일 기준으로 세 별에서 PoC 와 같거나 낮고 TOI-451 에서 +1.7 % 다. SG 2일(PoC)은 네 별에서 8h 통과의 27~32 % 를 깎는다. 창 1일 이상에서 방법을 biweight 로 바꾸는 것이 측정한 요인 중 가장 큰 개선이다.

**품질 마스크.** QUALITY==0 과 비트마스크 175·7407(2절, lightkurve v1.11.3 의 DEFAULT/HARD 와 일치, 현재 main 과는 다름)은 네 별에서 점 13~31개 차이, 지표 차이 없음. 플래그가 켜진 점은 대부분 flux 도 NaN 이다. QUALITY==0 을 유지한다. 현재 lightkurve 기본값(17087)은 비교하지 않았다.

**구간 분리.** Sector 경계 강제 분리와 공백 0.3일은 네 별에서 기준과 동일. Sector 사이 공백은 항상 0.5일을 넘었다. 공백 0.5일 규칙을 유지하고 Sector 경계 분리는 코드에 넣어 두되(무해) 별도 결정 사항으로 두지 않는다.

**가장자리 마스크.** 구간 시작·끝 6·12시간 제외는 네 별에서 잡음을 0~4 %(대부분 2 % 미만, 저잡음 별에서 최대 −3.9 %) 낮추는 대신 점을 5~13 % 잃는다(5.4). 이 표본에서는 도입 근거가 없어 넣지 않는다. 데이터 범위가 정해진 뒤 특정 Sector 에서 산란광 구간이 실제로 문제가 되면 그 Sector 에만 적용하는 것을 다시 검토한다.

**2단계 detrending.** 측정한 3일 → 1일 biweight 는 1일 단독과 8h 보존 ±0.01·잡음 ±1 % 안이고 계산은 2배다. 3일 → 0.5일은 0.5일 단독처럼 8h 통과를 지운다. 3일 → 1일 SG 는 1일 SG 단독과 같다. 세 조합 모두 이득이 확인되지 않아 도입하지 않는다. 활동성 별(TOI-451)에서 깊이를 유지하면서 잡음을 낮춘 조합은 측정한 범위 안에 없었다. 다른 창·방법 조합에 대한 결론은 아니다.

- 창 1일 biweight 도 잡음보다 얕은 8h 통과(500~1,000 ppm)는 10~25 % 깎인다. 통과 마스킹 후 재적합, 또는 변광 크기에 따라 창을 1~2일에서 고르는 규칙(예: 회전 주기 추정 → 창 = 회전 주기의 일정 비율)이 후속 후보다. 어느 쪽이 필요한지는 A Task 의 BLS 회수율로 판단한다.
- **"조용한 별에는 2일 창 허용"** 은 후속 후보다. 2일 창은 조용한 세 별에서 8h 보존 0.98~1.00 으로 1일보다 높지만, 어떤 별을 "조용한 별" 로 판정할지(변광 진폭·회전 주기 기준)가 정해지지 않았고 이 실험에서 그 기준을 측정하지 않았다. 적용 기준이 정해지기 전에는 제안 기본값에 넣지 않는다.
- 활동성 별의 변광 잡음(TOI-451 에서 창 2일 +42 %): 측정한 가장자리 마스크·2단계 조합 중 깊이를 유지하면서 잡음을 낮춘 것은 없었다(5.4). 창 1일에서는 잡음이 기준 대비 +1.7 % 이므로 v1 에서는 그대로 두고, 회전 주기 기반 창 선택이나 통과 마스킹 재적합은 위 항목과 함께 후속 후보로 둔다.
- 깊이 보존율은 겉보기 비율이며 신호별 불확실성을 측정하지 않았다(3절). 다중 신호 쌍의 1 을 넘는 값 해석과 오차 범위 산정은 지표 보완 항목이다.
- WASP-62 에서 biweight 가 잡음을 20 % 낮춘 원인(Sector 계통 오차 추적) 확인.
- 경계 비율 지표의 저잡음 별 해석(π Men 0.98)과 지표 정의 보완.
- 이 표본 4개 별은 실험용 고정 입력이다. 데이터 범위(DEC-01)가 정해지면 그 표본에서 제안값(biweight, 창 1일)을 재확인한다.
- 잡음 바탕곡선은 TOI-270 만 실행했다(5.2). 다른 세 별의 잡음 바탕곡선은 결론을 바꿀 가능성이 낮아 생략했고, 필요하면 같은 명령으로 추가한다.

## 7. 정하지 않는 것

최종 확정(팀 리뷰), BLS 격자·품질 게이트(A Task), 통과 마스킹 후 재적합 같은 v1 에 없는 방법(후속 후보), 운영 커널 구현(구현 1). 데이터 범위(DEC-01)가 정해지면 그 표본에서 제안값을 다시 확인한다.
