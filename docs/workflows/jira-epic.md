# Jira Epic 작성 가이드

## 이 문서를 읽는 경우

`에픽 만들어줘`, `여러 작업을 묶어줘`, `Epic 내용 작성해줘`

## 원칙

- Epic은 여러 Task가 함께 달성할 목표와 범위를 묶는다.
- Epic 자체의 작업 브랜치나 MR을 만들지 않는다.
- 구현 가능한 단위는 각각 Task로 분리하고 Epic에 연결한다.
- Story와 Sub-task는 사용하지 않는다.
- 실제 Jira 생성은 사용자가 명시적으로 요청하고 연결 도구가 있을 때만 수행한다. “내용 작성” 요청이면 복사할 내용만 제공한다.

## 작성 형식

```markdown
## 목표

## 배경

## 범위
- 포함:
- 제외:

## 하위 Task
- [ ] 독립적으로 검증 가능한 작업

## 완료 기준
- [ ] 모든 필수 Task 완료
- [ ] 통합 검증과 산출물 확인

## 관련 문서
```

하위 Task는 [Task 가이드](jira-task.md)에 따라 작성한다.
