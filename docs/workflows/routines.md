# 반복 절차 모음

## 이 문서를 읽는 경우

`자주 쓰는 명령 알려줘`, `이 절차 또 해줘`, `저번에 하던 방식대로 해줘`, `이 작업 순서 정리해줘`

## 등록 기준

- 같은 명령·절차를 서로 다른 문서나 대화에서 3회 이상 반복 설명했을 때만 여기에 모은다.
- 이미 담당 가이드가 있는 절차는 등록하지 않고 그 가이드를 링크한다. 브랜치·커밋·MR·Jira·보고서는 각각의 정본을 따른다.
- 한 항목이 자체 판단 규칙을 갖게 될 만큼 커지면 별도 문서로 분리하고 [워크플로 안내](README.md)의 입력 매칭 표에 등록한다.

## 작성 형식

각 항목은 제목, 실행 조건, 명령, 확인 방법 순으로 짧게 적는다. 실행 결과 로그와 전체 출력은 붙이지 않는다.

```markdown
### 절차 이름

- 실행 조건: 언제 쓰는지 한 줄
- 명령: 실제 실행할 명령 또는 단계
- 확인: 성공 여부를 판단하는 기준
```

## 절차 목록

아직 등록된 절차가 없다. 등록 기준을 충족한 절차가 생기면 이 절 아래에 추가한다.

공통 안전 규칙은 [AGENTS.md](../../AGENTS.md), 문서 생성·이동·삭제 규칙은 [문서 생명주기](documentation.md)를 따른다.
