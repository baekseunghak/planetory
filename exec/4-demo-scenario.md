# 4. 시연 시나리오

> 기준: `develop` `e2c7c19b`(2026-09-28). 화면 문구·클릭 순서의 정본은 [발표 시연 안내](../apps/frontend/src/cinema/DEMO.md)이고, 실서비스 발표자 계정은 [시연 발표자 계정 준비](../docs/operations/demo-account-runbook.md)를 따른다.

## 0. 시연 환경

| 환경 | 주소 | 로그인 | 쓰는 시나리오 |
| --- | --- | --- | --- |
| 실서비스 | `https://app.planetory.space` | SSAFY 또는 Google 계정 | 2·3 (발표자 계정: 은하에 별 2,000개가 열린 상태, 2026-09-27 준비) |
| 발표 시연 서버 | `http://127.0.0.1:58390` (발표자 노트북) | 화면의 `SSAFY 계정으로 로그인`(합성 로그인) | 1, 그리고 실서비스 장애 시 2·3 대체 |

- 두 환경은 같은 화면(은하 한 장면 위의 시네마 UI, 분석 새 디자인)이다. 발표 시연 서버는 백엔드·DB 없이 노트북 메모리의 합성 세계로 돌고, 튜토리얼·탐사 별 10개만 실제 TESS 관측 자료다.
- 운영 튜토리얼 1~5번은 시연 서버와 같은 실제 별이다: 1 WASP-62(TIC 149603524), 2 L 98-59(307210830), 3 TIC 279569718(식쌍성), 4 TOI-184(300871545, 거짓 양성), 5 TIC 278956474(식쌍성 신호 2개).
- 패널은 별을 TIC 번호로, 행성을 "행성 N"으로 부른다(서비스 규칙). 실제 이름은 `NASA 행성 자료 보기`에 나온다.

### 0.1 준비물

- Chrome, 그래픽 가속 켬(설정 → 시스템 → "가능한 경우 그래픽 가속 사용", `chrome://gpu`에서 WebGL이 Hardware accelerated)
- 화면 폭 1024px 이상(권장 1920×1080 또는 1440×900), 브라우저 확대 100%
- 발표 시연 서버: Node 22.12 이상, `apps/frontend/.real-sample/`(실제 별 10개). 없으면 발표 전에 `tools/real-sample/README.md`로 만든다(MAST 다운로드 필요)

### 0.2 발표 시연 서버 띄우기

```powershell
cd apps/frontend
npm ci
npm run dev:cinema          # http://127.0.0.1:58390
```

- 시작 줄에 `real TESS sample 10 stars`와 `analysis new`가 보여야 한다. `합성`만 보이면 `.real-sample/`이 없는 것이다.
- 포트가 겹치면 `$env:CINEMA_PORT=58391; npm run dev:cinema` 후 아래 주소의 포트도 바꾼다.
- 리허설 확인(선택): 다른 터미널에서 `$env:CINEMA_PORT=58390; node scripts/cinema-smoke.mjs` → `5/5 passed`.
- 화면 위 가운데의 `DEMO` 탭은 평소 숨어 있다. 마우스를 올리거나 `Alt+Shift+D`로 연다.

## 1. 시나리오 1 — 처음 온 탐사자가 실제 행성 WASP-62 b를 찾는다

시작 주소: `http://127.0.0.1:58390/api/dev-cinema/session?as=newcomer&start=login`<br>
(또는 `DEMO` 탭 → `로그인 화면에서 시작` 체크 → `처음 온 탐사자`. 실서비스에서는 처음 가입하는 계정이면 같은 흐름이다.)

| # | 화면 | 동작 (클릭 위치) | 보여 줄 것·기대 결과 |
| --- | --- | --- | --- |
| 1-1 | 로그인 | `SSAFY 계정으로 로그인` | 멀리 있는 은하 위로 네 줄의 이야기가 하나씩 나온다(약 10초, 회원마다 한 번) |
| 1-2 | 소개 | `시작하기` (바로 넘기려면 오른쪽 아래 `건너뛰기` 또는 `Esc`) | 은하로 날아드는 장면. 파란 1–5 튜토리얼 표시가 모두 화면에 든 구도로 끝난 뒤 튜토리얼 1(WASP-62)로 스스로 날아간다 |
| 1-3 | 별 패널 (선택) | 패널의 `← 나의 은하` → 은하에서 파란 `1` 마커 | "파란 1번 별을 눌러 시작하세요." 안내. 파란 1–5 마커를 설명한다 |
| 1-4 | 별 패널 | `분석 시작` | 분석 화면(새 디자인) |
| 1-5 | 분석 — 주기 | 아래 패널의 `1위` 봉우리 칩(4.4118일) | 가운데에 접힌 곡선이 나온다 |
| 1-6 | 분석 — 구간 | 접힌 곡선의 깊은 골(위상 약 0.71, 왼쪽 복제는 약 -0.29)을 골 폭보다 조금 넓게 왼쪽 → 오른쪽 드래그(좁으면 휠로 확대) | 구간이 `0.69–0.74` 정도로 잡힌다 |
| 1-7 | 분석 — 판단 | 오른쪽 판단 칸 `행성 같음` → `제출값 확인` → `제출하기` | 제출 |
| 1-8 | 통과 장면 | 1초 뒤 오른쪽 아래 `건너뛰기` 또는 `Esc` | 카드 "알려진 행성 WASP-62 b를 직접 찾아냈습니다 · 행성 1 · 주기 4.412일 · 지속 3.0시간 · 깊이 1.32%" |
| 1-9 | 발견 카드 | `은하로 돌아가기` | 새 별 점화(TOI-270, 빨간 `!`). 상단 `발견한 별` 5 → 6 |
| 1-10 | 은하 (선택) | 새로 켜진 별 | TOI-270 패널 |

- 1440×900과 1024×768에서 주기도·접힌 곡선·판단 칸 버튼(`제출값 확인`·`제출하기`)이 스크롤 없이 보인다. 위 띠의 튜토리얼 풀이는 `풀이 닫기`로 닫는다.
- 구간이 골을 비켜 가면 "이번 구간에서는 신호를 찾지 못했습니다"와 판단 칸에 `구간 다시 잡기`·`주기 다시 고르기`가 나온다. 골을 다시 잡아 제출한다.
- `아닌 것 같음`을 고르면 "구간은 맞았고, 판단은 달랐습니다" 카드가 나온다(성과 미인정, 점화 없음).
- 판단 칸의 `결과 자세히 보기`(카드의 같은 버튼)가 결과 화면을 연다. 행성이 여럿인 별(튜토리얼 2·5)은 결과의 `다음 곡선 단계로`로 이어 간다.

## 4. 처음으로 되돌리기 (시연 서버)

- 같은 시나리오를 새로: 시나리오 주소를 다시 열거나 `DEMO` 탭 `지금 세계 처음으로`, 또는 `curl.exe -X POST http://127.0.0.1:58390/api/dev-cinema/reset`
- 새 세계마다 제출 번호가 새로 시작하므로 통과·점화 장면은 리허설 뒤에도 다시 나온다.
- 서버 재시작: `Ctrl+C` 후 `npm run dev:cinema`

## 5. 그래픽이 느릴 때

1. 오른쪽 아래 `빛 효과 켬` → `끔`
2. 같은 탭에서 `…/login?power=reduced`(더 낮게 `low`)를 한 번 연 뒤 진행한다. 되돌리기는 `?power=auto`
3. 마지막 수단 `?power=list`: 3D 대신 별 목록

원격 데스크톱처럼 소프트웨어 그래픽이면 저절로 낮은 단계로 그린다. 느려지면 "화면이 느려 그래픽을 낮췄습니다"가 잠깐 보인다.
