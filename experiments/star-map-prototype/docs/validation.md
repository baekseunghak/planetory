# 검증 기록 — 2026-09-08

이번 기록은 저장소에 정리한 소스를 대상으로 한 실행 결과다. 기존 9월 7일 시제품 기록을 새 테스트 결과로 옮겨 적지 않았다.

## 환경

- Windows, Chrome 데스크톱, 1440×709 화면.
- Python 3.12.14, NumPy 2.5.2, Astropy 7.2.2. 데이터 재생성에는 기존 TESS 실험의 설치된 환경을 사용했다.
- Node.js로 JS 구문 및 좌표 검증을 실행했다.
- 로컬 HTTP 서버 58219에서 `spec/`, `proposal/`, `dist/` 실행.

두 버전 각각에서 다음을 확인했다.

- 처음에는 첫 튜토리얼 별 하나만 선택 가능.
- 첫 별 선택 → 실제 S3/4/5 광도곡선 미리보기 → 안내 완료 시연.
- 새 별 2개 해금 후 각각 분석 진입. L 98-59는 S2/5/8, CM Draconis는 S16 표시.
- 분석에서 지도 복귀, 새로고침 후 선택 및 분석 진행 복원.
- 안내 완료 뒤 첫 별은 분석 중, 발견 행성은 0개로 유지.
- 명세안 키보드 이동·축소, 약 10%에서 별 2개 묶음 생성 및 클릭 확대.
- 제안안 S3 관측 영역 활성화: 첫 별 방향에 CAM 3 / CCD 4 표시를 시각 확인.

- 제안안 방향키 이동, `+` 키 시야각 55° → 44°, Sector 16 선택·영역 이동 시 118°.

## 확인 중 수정한 문제

분석에 처음 들어갔다가 바로 지도로 돌아오면 작은 별 상태 문구가 ‘자유 탐사’로 남고 상세 정보만 ‘분석 중’으로 바뀌었다. 두 버전의 지도 DOM 갱신 판단에 `started` 상태가 빠져 있었다. 해당 상태를 갱신 키에 포함했다.

수정 후 캐시가 없는 localhost 실행에서 명세안 TIC 199574208, 제안안 TIC 307210830을 각각 미시작 상태로 선택 → 분석 진입 → **새로고침 없이 즉시 지도 복귀**하여 지도 문구가 ‘분석 중’으로 바뀌는 것을 확인했다. 단일 HTML도 수정한 코드로 다시 생성했다.
