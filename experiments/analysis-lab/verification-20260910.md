브라우저 캡처와 실행 출력은 로컬 `artifacts/`에 남기며 Git에는 포함하지 않는다. 주기 변경 시 Canvas 유지 검사는 DOM 교체 여부를 확인한 것이며 프레임 단위 성능 측정은 아니다.

## 검증 범위

데이터 준비 뒤 README 순서대로 실행할 수 있다. 원본 FITS·생성 관측 JSON·의존성·빌드 산출물은 Git에서 제외한다. 따라서 새 checkout에서 관측 화면을 보려면 README에 명시한 입력 자료가 필요하다.

홈은 정적 이미지이며 실제 지도와 연동되지 않는다. 서버 제출·채점·성과·공개·운영 Bundle 전환, 과학적 적합성, 접근성 전체 감사, 성능 벤치마크는 이번 검증에 포함하지 않는다. 시안의 20배 확대는 현행 요구사항의 8배 기준과 다른 사용자 피드백 실험이다.
