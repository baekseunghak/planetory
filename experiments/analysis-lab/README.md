# Planetory 분석실 공간 시안

《아이언맨 2》의 자비스 작업실을 참고한 독립 React 실험입니다. NASA/SDO의 항성 참고 이미지 위로 네 투명 패널과 받침대가 배치됩니다. 우주선·앞창은 포함하지 않습니다. 운영 프론트나 요구사항 기준선을 바꾸는 구현이 아닙니다.

- Jira: [S15P21C206-50](https://ssafy.atlassian.net/browse/S15P21C206-50), `experiment/S15P21C206-50-web-analysis-prototype`.
- 관련 계약·상세 명세: `S15P21C206-49`. 기존 [analysis-ui](../analysis-ui/README.md)와 같은 Task에서 검토하는 두 번째 배치 시안입니다.

## 실행

Node.js 22.12 이상과 pnpm 11.19.0을 사용합니다. 아래 명령은 프로젝트 루트에서 시작합니다.

```sh
cd experiments/analysis-lab
pnpm install --frozen-lockfile
pnpm data:prepare
pnpm data:check
pnpm dev
```

관측 JSON은 Git에 포함하지 않습니다. `data:prepare` 전에 `experiments/analysis-ui/public/observations/`에 기존 export의 `toi270.json`과 **그 파일을 만든 원본 `manifest.json`**이 있어야 합니다. 제공받은 두 파일을 해당 폴더에 복사하거나, [analysis-ui의 데이터 준비 절차](../analysis-ui/scripts/README-observations.md)에 따라 저장된 FITS에서 export합니다. 원본 FITS나 다른 작업 폴더를 자동 탐색·다운로드하지 않습니다.

이미 export한 파일이 다른 위치에 있으면 `pnpm data:prepare --source-dir "<관측 JSON 폴더>"`로 지정합니다. 동일 입력을 다시 대조하려면 `pnpm data:check --source-dir "<관측 JSON 폴더>"`를 사용합니다. 경로는 명령을 실행한 폴더를 기준으로 해석합니다. 새 checkout에 데이터가 없으면 화면에 로딩 실패·재시도가 표시되며, 데이터가 필요한 차트 검사도 준비 후 실행해야 합니다. 자세한 입력·변환 규칙은 [OBSERVATION-SOURCE.md](OBSERVATION-SOURCE.md)를 참고합니다.

브라우저에서 <http://127.0.0.1:5175/>를 엽니다. `pnpm build`는 `dist/`에 독립 정적 배포물을 생성합니다. 개발·미리보기 서버는 `0.0.0.0:5175`에 바인딩합니다. 같은 네트워크의 다른 기기에서는 `http://<이 PC의 IPv4 주소>:5175/?backdrop=home`으로 접속합니다.

## 시안에서 볼 부분

`http://127.0.0.1:5175/?backdrop=home`은 홈 위에 분석창을 겹치는 **간단한 배치 테스트**입니다. 시작 화면의 `TOI-270 분석창 열기`와 분석 화면의 `홈으로 돌아가기`로 비교합니다. 입력은 닫았다 열어도 유지되지만 새로고침하면 초기화됩니다. 홈은 원격 `develop`의 `a8775c9`에 포함된 `experiments/galaxy-map-prototype/docs/screenshots/01-overview.png`를 그대로 복사한 정적 배경(`public/images/home-preview.png`)입니다. 지도·홈 버튼·API는 연결하지 않았고 기존 분석실 기능만 위에 띄웁니다. `?backdrop=home`을 빼면 태양 배경의 원래 시안입니다.

홈 배경의 데스크톱 화면(901px 이상)은 **좌상 원본 · 우상 주기도 · 좌하 접힌 곡선과 미세 조정 · 우하 판단**의 2×2 배치입니다. 두 행은 패널 사이 간격을 뺀 높이의 40:60이며 그래프 면은 정면을 향합니다. 원본 패널의 관측 요약은 한 줄로, 판단 패널의 근거와 메모는 나란히 배치합니다. 좁은 화면은 기존 세로 배치를 사용합니다.

홈 시안의 항성 정보와 로딩 상태는 좌상 원본 패널, 브랜드·조명·안내·홈 복귀는 우상 주기도 패널, 분석 단계는 좌하 접힌 곡선 패널에 포함합니다. 별도 상단 헤더 없이 네 패널에 공간을 배분합니다.

- 왼쪽: 원본 밝기 변화와 관측 요약.
- 중앙: 선택한 주기로 접힌 곡선, 확대, 주기 미세 조정, 위상 구간 선택.
- 중앙 아래: 저장된 BLS 주기도와 상위 봉우리 선택.
- 오른쪽: 세 가지 판단, 선택 근거와 메모, 제출값 확인.
- 상단 `화면 접기` → `분석 시작`으로 패널이 모이는 동작을 다시 봅니다. 조명 버튼으로 실내 밝기를 바꿀 수 있습니다.
- 차트 제목 옆 확대 버튼으로 정면의 큰 그래프를 봅니다. 모바일에서는 패널을 한 열로 배치하며, 581–900px에서는 보조 패널을 두 열로 배치합니다.

슬라이더는 **주기 미세 조정** 전용입니다. 가려짐 구간용 외부 슬라이더와 고정 배율 버튼은 없앴습니다.

| 그래프 조작                                       | 동작                                                                      |
| ------------------------------------------------- | ------------------------------------------------------------------------- |
| 접힌 곡선 기본 드래그                             | 새로운 가려짐 구간 선택                                                   |
| 접힌 곡선 `Shift`+드래그                          | 가로 이동. 선택·판단은 유지                                               |
| 원본 곡선·주기도 기본 드래그                      | 가로 이동                                                                 |
| 마우스 휠                                         | 포인터 기준 가로 확대·축소. 접힌 곡선 1–20배, 다른 그래프 1–8배. y축 고정 |
| 더블클릭 / 키보드 `0`                             | 전체 보기                                                                 |
| 차트에 포커스한 뒤 `+` / `-`                      | 접힌 곡선 1·2·4·8·16·20배, 다른 그래프 1·2·4·8배                          |
| 밴드 양 끝 핸들 드래그 / 핸들에 포커스하고 방향키 | 가려짐 경계 조절                                                          |
| 주기도 아래 봉우리 버튼                           | 해당 봉우리 주기 선택                                                     |

인라인/확대창은 같은 차트 뷰를 공유합니다. 다이얼로그는 Escape로 닫습니다. 시스템의 동작 줄이기 설정에서는 패널 전환을 생략합니다. 사용자 피드백으로 접힌 곡선의 모드 전환 버튼을 없애고 기본 드래그 선택·Shift+드래그 이동으로 통일했습니다. 접힌 곡선 20배 확대는 이번 시안의 변경이며, 현재 EXP-13의 8배 기준과 차이가 있습니다.

## 데이터와 범위

실제 TOI-270 관측점 44,551개와 저장된 BLS 8,000점을 사용합니다. 변환 근거와 재검증 방법은 [OBSERVATION-SOURCE.md](OBSERVATION-SOURCE.md)에 있습니다. 이 자료는 이전 실험의 정리된 관측 데이터이며, 현재 운영 Bundle의 10분 비닝 계약을 구현한 파일은 아닙니다.

주기를 바꾸면 모든 관측점을 같은 기준 시각으로 다시 접습니다. 화면의 구간 중앙값과 자동 초기 가려짐 위치는 시각화를 위한 제안이며, 신호 매칭이나 행성 판정이 아닙니다. 접기 그래프의 음수 위상은 0 경계 주변을 보기 위한 표시 좌표입니다. 확인창에서는 시작 위상을 0–1로 정규화하고, 경계를 넘는 끝 위상은 1보다 크게 유지합니다.

주기나 구간이 바뀌면 이후 판단·근거·메모를 초기화합니다. 잘못되었거나 아직 적용되지 않은 주기 입력은 확인을 막습니다. 미세 조정은 접힌 곡선의 확대 배율만 유지하고 새 접기 중심에 재배치합니다. 새 봉우리를 선택하면 1배로 돌아갑니다. Canvas의 다음 그림을 오프스크린에 완성한 뒤 한 번에 교체합니다.

운영 후보표 API가 연결되지 않아 미세 조정 범위는 저장된 BLS의 해당 주기 주변 격자 4칸씩, step은 격자 간격의 1/50로 만드는 **시안 규칙**입니다. 운영에서는 EXP-05의 후보별 `period_min/max/step`을 사용해야 합니다. 화면용 epoch는 위상 경계를 정규화하고 관측 범위 안에서 기준 시각에 가장 가까운 통과 중심을 고르며, 동률이면 더 이른 시각을 택합니다.

배경은 **태양**의 AIA 171 Å 관측 이미지이며 TOI-270 사진이 아닙니다. 과학 분석 입력에도 쓰지 않습니다. 자산 출처·크레딧은 [BACKGROUND-SOURCE.md](BACKGROUND-SOURCE.md)에 기록했습니다.

미세 조정 범위, 단계 안내, 자동 초기 주기·구간은 시안용입니다. 확인 도구의 실제 계산, 잔차 생성, 서버 제출, 매칭·정답 판정, 성과, 기록 저장, 공개는 연결하지 않았습니다. 새로고침하면 입력은 초기화됩니다. 네 패널의 크기·배치·투명도·움직임을 검토하는 용도입니다.

## 확인한 항목

이번 작업에서 다시 실행한 명령과 브라우저 9개 흐름의 결과는 [2026-09-10 검증 기록](verification-20260910.md)에 정리했습니다. 실제 Shift 키와 포인터 이동, 휠·키보드 20배 확대, 모바일 확인창, 데이터 실패 후 재시도까지 통과했습니다.

2026-09-10 Jira 작업 브랜치의 별도 작업 폴더에서 `pnpm install --frozen-lockfile`, `pnpm data:prepare`, `pnpm data:check`, `pnpm test`, `pnpm build`를 재실행했습니다. Node 24.19.0·pnpm 11.19.0에서 차트 검사 17개와 분석 상태 검사가 통과했습니다. `--source-dir`의 정상 입력과 누락 입력(exit 1 안내)도 확인했습니다. 데이터는 기존 export를 복사해 손실 없는 변환을 대조했으며 FITS를 다시 읽거나 BLS를 재계산하지 않았습니다. 아래 브라우저 항목은 시안 구현 중의 확인 범위입니다.

- 프로덕션 빌드.
- 원본 관측 JSON·manifest에 대한 데이터 변환 검증(모든 값과 순서 보존).
- 그래프 수학 검사: 두 주기 반복, 포인터 기준 20배 확대·상한, 다른 그래프의 8배 상한, 로그 주기축, 팬, 경계 선택, 키보드 배율.
- 분석 상태 검사: 경계를 넘는 위상 구간, 반복 구간의 동일 epoch, 가까운 epoch·동률·관측 범위, 잘못된 입력, BLS 격자 기반 미세 조정.
- 브라우저에서 접기/펼치기, 구간 선택 → 판단/근거/메모 → 제출값 확인, 확대창과 Escape 복귀.
- 브라우저에서 접힌 곡선 기본 드래그로 구간 선택, 휠·키보드 20배 확대와 전체 보기, 핸들·경계 방향키, 미세 조정과 판단·메모 초기화.
- 0 주기 차단, 미세 조정 후 구간·판단·메모 초기화와 확대 배율 유지, 새 봉우리 선택 시 1배 초기화.
- 인라인/확대창 배율 공유와 Escape 복귀, 390px 모바일에서 가로 넘침 없이 구간 선택·판단·확인창·확대창 사용.
- 데스크톱에서 배경·투명 패널 배치 확인, 검사 중 브라우저 오류·경고 없음.
