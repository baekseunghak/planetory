## 재현 후 수정한 문제

- 구간 선택 중 Escape를 누르면 구간이 지워지는 동시에 전역 단축키로 분석 화면까지 닫혔다. 차트가 처리한 Escape의 전파를 막아 구간만 지우도록 수정했다.
- Worker 응답을 누락하면 16초 이후에도 오류 없이 단계 이동이 잠겨 있었다. 15초 제한과 재시도를 추가하고, 시간 초과된 Worker를 종료해 늦은 응답을 버리도록 수정했다.
- 최대 선택 폭이 1인 데이터를 입력 검증은 허용했지만 구간 선택 함수는 거부했다. 입력 검증도 1 미만으로 통일하고 기존 두 테스트에 경계 사례를 추가했다.
- 광도곡선에는 구현되지 않은 스크롤 확대 안내가 표시됐다. 시간에 따른 밝기와 관측 구간을 살펴보라는 안내로 바꿨다.

## 검증 범위

세 관측 JSON의 해시·식별자·점 개수·관측 구간은 테스트에서 대조했다. FITS 재처리와 BLS 재계산, 실제 API·DB·서버 제출·성과·게시, 천구 투영, 여러 화면 크기의 전체 검증은 수행하지 않았다. 기존 `analysis-ui` 및 `analysis-lab`을 이번 확인 대상으로 실행하지 않았으며, 현재 서비스 요구사항의 구현 완료를 의미하지 않는다. 범위 차이는 [README](README.md)를 따른다.
