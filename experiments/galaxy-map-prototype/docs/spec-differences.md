관측 회차·밝기 등급(HOME-08), 등급·유형별 성과(GRD-07, AT-29), 분석·결과·스레드 연결은 화면에 유지했습니다. 유지된 화면의 모든 상태를 이번에 다시 검증했다는 뜻은 아닙니다.

자유 회전, 알려진 별칭, 0.001~10,000배 확대 범위는 제안 기능입니다. 일반 색상값·서체·모서리 등은 DEC-07의 참고 디자인 범위이지만, 상태별 색 의미나 배치·성능 규칙과는 구분합니다. 입체감 자체를 명세 위반이라고 단정하지 않습니다.

분석·채점·서버는 로컬 검증용 구현입니다. 기존 실서비스나 팀 백엔드의 완성 상태를 의미하지 않습니다. 이 차이를 팀이 수용할지 판단하는 것이 PoC의 목적이며, 정식 도입에는 별도 합의와 구현 작업이 필요합니다.
