대상: `experiments/galaxy-map-prototype/`, Jira S15P21C206-45. 기준 develop 커밋 `809b938`에서 새 작업 폴더를 만들고, 기존 `node_modules`, `.local`, `dist`를 복사하지 않은 상태로 검증했습니다.

## 실행 환경과 결과

- Windows, Node.js **24.18.0**, npm **11.16.0**.
- React 19.2.6 / TypeScript 5.9.3 / Vite 8.2.2 / Playwright 1.63.0.
- `npm ci`: 새 설치 완료, npm 감사 결과 취약점 0개.
- `npm run build`: 타입 검사·프로덕션 빌드 통과.
- `npm test`: **38개 통과**, 실패·건너뜀 0. 공통 API 클라이언트·도메인·공유 로직에 대한 단위 테스트이며 은하 화면 전체의 SRS 합격을 의미하지 않습니다.
- `npx playwright install chromium` 후 `npm run test:galaxy`: **6개 통과**, 약 59초. 테스트 전용 API/프론트 자동 기동, 새 상태 생성, 종료까지 확인했습니다.
- `.env.example` API 주소와 Vite 기본값을 58242로 일치시켰고, 브라우저 테스트는 환경 변수로 58246을 지정해 분리를 검증했습니다.

브라우저 원시 보고서의 개인 PC 경로를 제외한 [검증 결과](browser-results.json)를 함께 보관합니다. 재실행 결과·실패 추적은 Git에 넣지 않는 `test-results/galaxy/`에 생성됩니다.

## 성능 관찰의 해석

[관찰 JSON](observation.json): 1680×1050, DPR 1, 50,000개, draw call 2회. 이번 기본 headless Chromium은 **SwiftShader 소프트웨어 렌더러**를 사용했고 5초 중 100프레임, p95 약 **66.6ms**, 최악 약 **66.7ms**였습니다. 하드웨어 GPU의 60fps 측정 결과로 제시하지 않습니다. 브라우저 시험의 프레임 관찰은 실행·계측만 확인하며 성능 임계값을 합격시킨 테스트가 아닙니다.

## 보존·범위

[원본과 공유 코드의 SHA-256 비교](source-comparison.json)에서 화면·스타일·투영·렌더러·합성 배치·글꼴이 동일한지 확인했습니다. `server/http.ts`의 상태 경로 부모 폴더 생성 부분만 실행 재현성을 위해 조정했습니다. 패키징 설정과 문서는 공유용으로 별도 정리했습니다.

실제 OAuth·팀 운영 백엔드·과학 분석 엔진 연동, 모든 서비스 상태·브라우저·모바일, 명세 AT-71의 전체 성능 인수는 이번 검증 범위 밖입니다. 공유 코드가 SRS 전체를 만족한다는 결론을 내리지 않습니다. 해당 폴더의 GitLab 자동 CI는 구성하지 않았으며 로컬 증거를 제출합니다.

팀원의 새 환경 실행 확인, 리뷰 승인, MR 병합과 최종 인수 확인은 후속 단계입니다. Jira는 이 단계가 끝날 때까지 진행 중으로 유지합니다.
