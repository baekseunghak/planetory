사용자 승인으로 확정한 추가 정책:

1. 사용자 확정: 대상 별의 모든 공식 신호 스레드에서 현재 유효 공개 분석을 가진 회원을 별 단위로 중복 제거해 집계한다(COUNT DISTINCT 회원 ID). 여러 신호에 참여해도 1명이며 스레드별 N을 합산하지 않는다. 공개 취소·숨김 후 다른 유효 공개 분석이 남으면 포함하고, 하나도 없으면 제외한다. 핫 토픽·판단 분포의 신호별 집계는 변경하지 않는다.
2. 사용자 확정: 초기에는 공개 조회자에게 타인의 잔차 재계산 요청 기능을 제공하지 않는다. 제공 가능한 원본 그래프 또는 제출 스냅샷만 표시하고 둘 다 없으면 그래프 제공 불가를 안내한다. 원본과 잔차는 구분해 표시하고 나머지 공개 내용은 계속 표시한다. 본인 분석용 잔차 요청 API의 기존 권한은 유지한다. 미계산 상태는 status·jobId=null로 양쪽 명세에 반영했다. 실제 작업이 있을 때만 해당 상태·ID를 반환한다.

아래는 수정 전 발견 내역이다. 위 표에서 해결한 사항을 현재 미해결로 해석하지 않는다.

## 이미 맞는 부분

- 성과는 회원×신호 1회이며 서비스 공개와 탐사 제출이 같은 PostgreSQL 트랜잭션·공통 지급 함수를 사용한다.
- 내 별 목록은 서비스가 탐사 4.4절을 참조하고 타인의 비공개 별 목록은 403 `STAR_LIST_PRIVATE`로 처리한다.
- History 그래프는 사용자 원본 주기·durationHours·세그먼트 배열을 사용하고 스냅샷이 없으면 `snapshot:null`이다.
- 읽는 중 판 전환은 전체 재조회 최대 1회·이후 503이고, 쓰기의 `BUNDLE_CHANGED`와 구분한다.
- 일반 글·댓글 요청 키는 사용하지 않으며 탐사 제출은 본문 requestId로 별도 처리한다.

## 대화 결정과 현재 파일의 별도 차이

메모 공개와 초기 비공개 요청의 차이는 사용자에게 확인했고, 사용자가 현재 파일대로 공개를 선택하여 해소했다. 첫 방문 안내 완료 설정도 P0 추가를 승인했다.
