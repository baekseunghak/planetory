대상: [S15P21C206-133](https://ssafy.atlassian.net/browse/S15P21C206-133), 2026-09-14. 상태: **결정 반영 완료, MR 리뷰 중**.

이번 MR에서 확인할 결과는 세 가지다.

- 예전에 선택한 후보가 사라졌을 때 분석 화면·다시 풀기·히스토리가 각각 어떤 곡선을 보여주는지 통일했다.

기준은 2026-09-14 원격 `develop` `321f10b`의 SRS·ERD v1.2 변경안, 탐사 API Draft 0.3과 서비스 API다. #36·MR !25 완료는 초안 병합 기록이며 아래 정책 승인 기록이 아니다. 기존 기획 #31은 사용자 확인에 따라 완료로 취급한다.

## 2. C02-R1: 은퇴 후보의 세 경로

공통 입력: 원 제출 제거 조합 `{A,B}`, 현재 판에서 B 은퇴, 현재 진행 문맥 `{A,C}`. A와 C는 본인이 매칭한 활성 후보이고 재도전 대상 D는 활성·제거 집합 밖이라고 가정한다. 누적 매칭 집합과 현재 진행 문맥은 다른 값이다. 아래는 원본과 각 제거 조합의 캐시가 준비됐다는 조건이다.

| 경로 | 2026-09-14 결정 | 배열·안내 |
|---|---|---|
| 분석 복귀 5.1 | 최신 현재 진행 사용 | `{A,C}`, step 2, `notice=STEP_NOT_RESTORABLE` |
| 재도전 SUB-10·6.8 | 최신 현재 진행 사용 | `{A,C}`, step 2, `restored.step=false`, `restored.notice=STEP_NOT_RESTORABLE` |
| History CURRENT HIS-03·8.3 | 최신 원본 대체 | `{}`, step 0, `residualReproducible=false`, `fallbackReason=RETIRED_CANDIDATE` |
| History SUBMITTED | 당시 snapshot 유지 | `curve=null`; snapshot이 없으면 `snapshot=null` |

**결정:** 분석 복귀와 재도전은 SRS SUB-10의 최신 현재 진행 `{A,C}`로 통일한다. History CURRENT는 HIS-03의 원본 `{}`, History SUBMITTED는 `curve=null`과 당시 snapshot을 사용한다. `{A}`만 남기는 중간 문맥은 사용하지 않는다. 사용자가 2026-09-14 이 안을 선택했다.

배열 예시: 원본 `[1,0.99,0.98]`, A 모델 `[1,0.99,1]`, C 모델 `[1,1,0.98]`이면 A 제거 `[1,1,0.98]`, A+C 제거 `[1,1,1]`이다. B는 은퇴했으므로 현재 B 모델을 만들어 사용하지 않는다. 이 값은 경로 차이를 드러내는 합성 예시이며 과학 모델 승인값이 아니다.

캐시가 없으면 조회로 작업을 생성하지 않는다(D-14). 대상 D 자체가 은퇴한 재도전은 대체하지 않고 409 `CANDIDATE_RETIRED`. 조회로 누적 매칭·완료·원 제출을 변경하지 않는다.

결정 기록: 사용자 선택, 2026-09-14. 교차 검토: 강재민·백지웅, 공개/첨부 그래프 경계 백승학. 인계: A07·A08-1·A09, C02. 구현 리뷰는 남아 있지만 경로별 기대 결과는 위 표로 확정한다.

## 3. C02-R2: 기준 시각의 저장 범위와 환산

SRS v1.2 DAT-11·PublicationBundle의 세그먼트별 표현을 EXP-06·AT-95, ERD `publication_bundles`, API 2.5·5.1과 같은 Bundle 공통값으로 정정한다.

| 대안 | 저장·산정 | 필요한 변경 |
|---|---|---|
| Bundle 공통값 | 해당 판에 포함된 품질 통과 원본의 유한 time/flux 관측 시각 전체 중앙값 | SRS 세그먼트별 표현 정정, manifest와 API 공통값 전달 |
| 세그먼트별 값과 공통 접기 좌표 변환 | 세그먼트 원본 관측별 중앙값 저장, 공통 접기 기준 산정·변환을 별도 정의 | ERD/API에 세그먼트 기준 및 변환 계약 추가, 제출의 공통 좌표·기록 범위 명시 |

Bundle 공통안을 채택한다. 산정 입력은 포함된 모든 세그먼트에서 DAT-02 품질 필터를 통과하고 중복을 제거한 뒤 time·flux가 유한한 원본 관측 시각 전체다. 이를 정렬한 중앙값을 사용하며, 짝수 표본은 가운데 두 값의 평균을 쓴다. 유효 입력이 없으면 Bundle 공개를 실패시킨다. 세그먼트 중앙값들의 단순 평균이나 표시용 반올림값으로 대체하지 않는다. 예를 들어 세그먼트 원본 시각 `[100,102]`, `[110,112,114]`의 전체 중앙값은 110이고 세그먼트 중앙값의 평균 106.5는 사용하지 않는다. 산정값은 `publication_bundles`에 float64 round-trip 정밀도로 한 번 저장하며 세그먼트는 별도 기준 시각을 저장하지 않는다.

AT-118 공통 환산 사례: P=4일, 옛 T=100, phase=0.20~0.30 → epoch=101, duration=9.6시간. 현재 T=101이면 중심=0, 폭=0.1, phase=0.95~1.05. 현재 T=102이면 중심=0.75, phase=0.70~0.80. 절대 epoch와 duration은 변하지 않는다. 이 계산 예제는 저장 범위의 대안을 결정하지 않는다.

결정 기록: 사용자 선택, 2026-09-14. 결정 담당: 윤성용·강재민·김동혁, 소비자 확인 백지웅. 인계: [D06 #113](https://ssafy.atlassian.net/browse/S15P21C206-113). 구현 교차 검토는 남아 있지만 저장 범위와 산정 규칙은 Bundle 공통값으로 확정한다.

## 4. C02-R3: duration 상한과 추천 중첩

추천 밖 주기는 전체 격자 안이면 허용한다. 이는 모든 위상·duration이 허용되거나 후보 매칭에 성공한다는 뜻이 아니다.

6.2는 `minWindowDays/P` 이상의 위상 폭, `phaseWidthMax` 이하를 검사하고 사용자가 고른 봉우리의 `suggestedDurationHours × maxDurationMultipleOfSuggested`도 적용한다. DEC-19의 3배는 정답 인정 범위가 아니라 선택 폭 상한이며 운영값은 규칙 버전으로 관리한다.

`fineTune` 범위가 겹친다는 것은 봉우리가 합쳐진다는 뜻이 아니라 서로 다른 두 봉우리의 주기 조정 구간이 일부 겹친다는 뜻이다. 비교 입력 P=4일, phase 폭=0.1은 9.6시간이다. 추천 A의 duration=2시간, B=4시간, 배수=3이면 A를 고른 제출은 상한 6시간으로 거절하고 B를 고른 제출은 상한 12시간으로 허용한다.

제출은 `sourcePeakGridIndex`로 사용자가 고른 봉우리를 명시한다. 서버는 같은 `curveContext`에서 해당 `gridIndex`가 존재하고 조정 주기가 그 봉우리의 `fineTune` 안인지 확인한 뒤 그 봉우리의 duration만 사용한다. 주기도의 다른 위치를 직접 고르면 source는 null이고 Bundle 공통 `phaseWidthMax`만 적용한다. 서버는 주기 근접도·배열 순서로 봉우리를 추정하지 않는다.

`N_transits`(매칭 누적오차 통과 수), `N_peak`(표시 추천 수), 매칭 최소 창, UI 최소 선택 폭은 별도 필드·단위다. 현재 예제 수치는 실측을 대체하지 않는다.

결정 기록: 사용자 선택, 2026-09-14. 결정 담당: 윤성용·강재민·백지웅. 인계: [D20 #128](https://ssafy.atlassian.net/browse/S15P21C206-128), C09·A04. 선택 봉우리 식별과 중첩 처리는 확정했고, 3배 운영값의 실측 조정은 `rule_version` 변경으로 관리한다.

## 5. 유지할 소비자 계약

- D-13: 별의 모든 공식 신호 스레드에 참여한 회원의 합집합 크기. 스레드 A={u1,u2}, B={u2,u3}이면 3명이며 4명이 아니다. 취소·숨김 뒤 다른 유효 공개가 남은 회원은 포함한다.
- D-14: 결과·작업이 없으면 status/jobId 모두 null. 조회는 작업을 만들지 않으며 null을 QUEUED로 바꾸지 않는다.
- D-15: 타인 공개 그래프는 기존 공개 권한으로 조회하며 잔차 재계산을 제공하지 않는다. 원본/당시 snapshot 대체와 제공 불가 안내를 유지한다. 타인의 개인 작업 조회 권한을 추가하지 않는다.
- EXP-11: 홀짝·2차 식·V/U형 도구는 제공 곡선을 브라우저에서 계산한다.
