# 212 일반 글 반응·반응자 목록 구현·인수

Jira S15P21C206-212 / W13-2 · 하서진 · 2026-09-18. 상위 [프론트 README](../README.md), 정본 [서비스 API 8절](../../backend/docs/service-api-spec.md#reactions), [SRS COM-08](../../../docs/requirements/planetory-requirements-spec.md).

## 동작과 계약

- 일반 글에만 동의/비동의 버튼과 서버 합계를 표시한다. 선택된 버튼을 다시 누르면 취소한다. 본인 글도 허용하며 공식 스레드·공개 분석의 판단 통계와 분리한다. 공개 분석·댓글·성과 요청은 발생하지 않는다.
- `PUT /posts/:postId/my-reaction`에 최종 `AGREE`/`DISAGREE`/`NONE`을 보낸다. 티켓의 의미상 null/없음은 API의 NONE으로 인코딩한다. 임의 null이나 toggle 요청을 보내지 않는다.
- 같은 탭의 쓰기는 한 건씩 처리한다. 저장 중에도 마지막 선택은 갱신하고 앞 요청의 확정 응답 뒤 최신 선택만 전송한다. 오래된 조회·다른 글·로그아웃 전 요청은 현재 화면을 덮지 못한다. 합계를 프론트에서 더하거나 빼지 않는다.
- 통신/5xx/잘못된 성공 응답으로 결과가 불명확하면 자동 재전송하지 않는다. 현재 글 GET으로 서버 반응을 다시 확인한 후 직접 선택한다. 여러 탭·다른 사용자의 순서까지 보장하는 서버 버전 규칙은 추가하지 않는다.
- 합계 버튼을 누르면 현재 닉네임·프로필 링크를 dialog로 보여 준다. AGREE/DISAGREE별 size20·불투명 cursor로 모든 페이지를 순회하며 처음으로 돌아갈 수 있다. 합계와 목록의 조회 시점 차이를 안내한다. Escape/닫기 후 버튼으로 포커스를 돌린다.
- 숨김/삭제/권한403·404는 글/댓글/반응을 함께 가리고401은 공통 인증 처리로 개인 화면을 제거한다. 미정인 숨긴 글의 취소 허용·탈퇴 회원 보존 정책을 클라이언트가 정하지 않는다.
