### 명세 때문에 그대로 복제하지 않는 부분

- 로그인 장식 은하 외에는 임의 별을 채우지 않는다. 프로필·커뮤니티의 작은 은하는 기존 인증된 `/me/sky`와 타일 페이지에서 받은 회원 소유 좌표로만 그린다. 별이 없으면 빈 상태, 실패하면 재시도 안내를 표시한다. 타인 프로필에는 내 은하를 표시하지 않는다.
- 지도·행성의 개수, 좌표, 완료 여부, 등급을 프론트에서 계산해 성과로 인정하지 않는다. 시제품의 가상 성과 지급·계정 전환·리셋은 제품 화면에 이식하지 않는다.
- 지도 안의 실제 별과 혼동하지 않도록 장식 점 배경은 로그인/일반 서비스 페이지에만 사용한다. `/sky`에는 장식 별을 추가하지 않는다.
- HOME-08은 별·궤도·복귀 조작을 가리지 않도록 요구하지만 현재의 긴 도킹 패널을 강제하지는 않는다. 시제품처럼 정보를 가장자리에 배치하고 천체 투영 영역을 확보할 수 있다. 도킹 조건을 상세 구조 이식을 제외하는 근거로 사용한 1차 설명을 정정한다.
- NFR-17의 1024px 미만 데스크톱 안내와 NFR-18의 WebGL 대체 목록을 유지한다. 이번 실행 검사는 요청에 따라 Chrome으로 한정하며 제품의 지원 정책 자체를 고치지 않는다.
- 시제품의 가짜 이름/행성·미구현 화면·다른 계약의 API 호출을 복사하지 않는다.

## 코드와 실행

- `ServiceLayout.tsx` / `service-presentation.css`: 분석 영역을 제외한 페이지 배치와 공통 메뉴, 지도 가장자리 UI를 정한다.
- `QuestPanel.tsx`: 외부 접기·닫기와 별 선택 후 복귀할 초점을 처리한다. 기존 퀘스트 상태 계약은 그대로 사용한다.
- `GalaxyArtwork.tsx` / `MySkyPreview.tsx`: 로그인 장식과 회원의 실제 소유 별 미리보기를 분리한다. 2D canvas는 자료·크기 변경 시에만 그리며 지속 애니메이션 루프를 만들지 않는다.
- `CommunityAside.tsx`: 기존 핫 토픽 API의 짧은 목록과 내 은하를 재사용한다. 목록/상세의 오류와 보조 영역 오류는 각각 표시한다.
- `scripts/presentation-server.mjs`: 기존 HTTP fixture들을 조합한 로컬 검토 도구다. 운영 Vite 설정과 독립하며 가짜 데이터가 운영 빌드에 포함되지 않는다. 별 5,000개, 튜토리얼 5개 완료이며 실제 OAuth·DB·분석 서버 검증이 아니다.

```powershell
cd apps/frontend
npm ci
npm run dev:presentation
# http://127.0.0.1:58381/sky
# /me, /community, /community/hot-topics
```

원본 시제품과 기존 develop 5,000개 미리보기는 보존한다. 이 브랜치의 실제 제품 소스에 임시 HTTP 데이터를 공급해 비교하며 기존 시제품 서버 코드를 제품 코드로 교체하지 않는다.

### 실제 실행 결과

- `npm run build` / `npm run build:renderer`: 타입 검사·운영 빌드·fixture 제외 검사 통과. 지도 활성/비활성 빌드 모두 확인했다. 기존 500KB 청크 경고는 남아 있으며 이번 작업에서 번들 분할이나 성능 인수 완료를 주장하지 않는다.
- `npm test`: 단위 340개 통과.
- Chrome 145개 통과: 공통 기반 6, 인증 9, 퀘스트 11, 별 상세 9, 대체 목록 11, 커뮤니티 14, 글 15, 댓글 7, 반응 5, 첨부 9, 프로필 8, 검색 15, 핫 토픽 10, 이번 배치/개인 자료 경계 검사 6.
- 각 기능의 `playwright.<기능>.config.ts`로 `--project=chrome` 실행. 공통 기반은 `playwright.config.ts`의 `tests/browser/foundation.spec.ts`, 새 배치 검사는 `playwright.presentation.config.ts`다. Windows Vite 캐시 충돌을 피하기 위해 기능 검사는 순차 실행했으며 미리보기는 독립 캐시를 사용한다.
- 캡처를 직접 확인하며 로그인 정렬·버튼 대비, 안내 단계 간격, 최소 폭에서 상세와 목록 전환 버튼의 겹침을 수정했다. 지도 높이 836px/헤더 64px, 1024px의 상세 300px 도킹, 가로 넘침 없음, 초점 복귀와 767px 접근 안내를 확인했다.
- 기존 develop에서도 첨부 검사 3건이 실패했다. 합성 응답에 공용 그래프의 필수 `isPreviousSubmission`이 없었기 때문이다. fixture에 해당 값과 현재 접기의 기준시각을 보충하고, 과거 자리표시자 검사를 실제 SVG 그래프 검사로 바꾼 뒤 첨부 9건이 통과했다. 제품 그래프 파서는 변경하지 않았다.
- 소형 은하도 기존 타일을 읽으므로 프로필/커뮤니티 진입에 지도 읽기가 추가된다. 요청은 기존 중단·세션 정리 규칙을 사용한다. 이번 5,000개 화면 검증을 10만 개 성능 검증으로 해석하지 않는다.

운영의 `VITE_SKY_RENDERER_ENABLED=true` 설정은 기존 지도 활성 조건이다. 이 MR은 배포 플래그·OAuth·프록시 기본값을 바꾸지 않는다. 합성 HTTP 검증은 실제 운영 인수 `216`을 대체하지 않는다.
