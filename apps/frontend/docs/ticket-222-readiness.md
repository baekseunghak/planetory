# 222 탈퇴 화면 준비와 남은 정책 승인

2026-09-21 사용자의 프론트 우선 구현 요청을 반영해 서버가 제공하는 승인 정책을 읽는 화면과 실제 HTTP 호출 구조를 준비했다. 과거의 보관·재가입 약속을 새로 확정하지 않는다.

- [x] 미승인 available=false면 실행 버튼이 없다. 승인 version과 데이터 처리·재가입 안내 확인을 요구한다.
- [x] 준비와 실제 확정을 분리하며 중복 클릭/자동 재전송을 차단한다.
- [x] 확정 응답 유실은 전용 읽기 전용 결과 화면에서 확인한다. COMPLETED 확인 후 세션·임시 입력을 제거한다.
- [x] 결과 확인 GET은 인증 세션 취소 범위에서 분리한다. `/v1/me`가 먼저401이어도 HttpOnly 영수증 쿠키의 늦은200 응답을 받아야 하며, 자신의 signal·timeout은 그대로 적용한다.
- [x] Chrome3개: 미승인 비실행, 확정 응답 유실 후 읽기 복구·재전송0·로그인 차단, 세션401보다 늦은 영수증 결과 확인. 파서2개·클라이언트 취소 경계·타입검사.
- [ ] S26 보관·익명화·재가입 정책 승인 및 S27 생산자 교차 리뷰.222를 아직 완료 처리하지 않는다.
