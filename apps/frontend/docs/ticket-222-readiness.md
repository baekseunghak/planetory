## 2026-09-22 프론트 기준 후속 작업

기준: 원격 develop `fc29cc66`(223 후속 MR 병합 포함). 기존 222 작업 사본은 보존하고 `fix/S15P21C206-222-web-withdrawal-recovery`에서 진행한다. 사용자가 전달한 "백엔드가 프론트에 맞춰 진행"을 화면·HTTP 흐름의 기준으로 사용한다. 보관기간·재가입 여부까지 이미 정해졌다고 해석하지 않는다.

새 [탈퇴 직접 검사](../tests/p1/withdrawal-contract.spec.ts)는 실제 WithdrawalPage/WithdrawalStatusPage와 공용 API 클라이언트를 사용한다. 테스트마다 가상 회원과 응답을 격리하며 실제 회원 삭제 요청은 보내지 않는다. 수정 전 위 세 브라우저 상황은 실패로 재현했다. 기존의 정상·미승인·응답 유실 검사를 제거하거나 결과 확인을 다른 화면으로 대체하지 않는다.

첫 전체 검사에서 정상 confirm 완료 뒤 로그인으로 이동하는 문제도 재현했다. 결과 화면의 세션 정리 순서로 수정하고, 영수증 GET이503이어도 이미 확인된 완료의 로컬 정리를 유지하는 회귀를 추가했다. 경로 state는 로컬 정리 신호만 전달하며 서버 권한이나 화면의 성공 결과를 대신하지 않는다. 완료 표시는 영수증 GET의 유효한 응답에서만 한다.

### 이번 검증의 고정 범위

정책 원문 표시와 입력 검증, 준비·확정 순서/중복 방지, COMPLETED 후 로컬 세션·초안 제거, 정책 조회 장애·누락 문구, 준비 응답 유실, POLICY_CHANGED 재동의, 기존 처리 중 요청, READY/PROCESSING/FAILED 구분, 다른 요청의 성공 응답 거부, 결과401/404 비성공 처리, 기존의 세션401 뒤 늦은 영수증 GET을 확인한다. 관련 P1 회귀·단위·타입/운영 빌드를 함께 실행한다. 최종 실행 결과는 이 문서 마지막에 기록한다.

### 2026-09-22 Jira 실조회·종료 인계

사용자가 222 완료까지의 진행을 요청해 로그인된 Jira의 222·179·180 본문과 표시된 활동을 직접 확인했다. 222는 진행 중, 179는 완료, 180은 해야 할 일이다. **179를 미완료라고 다시 판정하거나 상태를 되돌리지 않는다.** 다만 179에 연결된 MR !154의 산출물과 최신 `origin/develop`의 DEC-11은 여전히 정책 초안·승인 대기로 적혀 있고, 확인한 본문·표시된 댓글에서는 실제 정책 버전과 승인된 데이터별 처리·기간·재가입 문구를 찾지 못했다. 이는 이미 합의된 정책이 없다거나 179 담당자가 승인하지 않았다는 단정이 아니라, 프론트가 소비할 승인 산출물의 위치·값을 현재 근거로 확인하지 못했다는 뜻이다.

222의 현행 본문은 정책 승인·서버 계약 확정을 별도 완료 조건으로 유지하며 S27 삭제·익명화 구현은 프론트 범위에서 제외한다. 180의 전체 구현 완료를 222의 새로운 선행 조건으로 추가하지 않는다. 222를 닫기 위해 필요한 제공자 인계는 다음 두 가지다.

1. **179 승인 산출물 연결:** 승인된 정책의 위치·버전과 `effects/retention/rejoining`의 실제 안내 문구를 제공한다. 안내와 원본 정책의 처리 대상·기간·재가입 의미가 일치하는지 대조한다. 이미 승인된 내용을 재결정하라는 요청이 아니다.
2. **180 제공자 계약 수용:** [P1 계약 5절](../../backend/docs/p1-service-contract.md#5-탈퇴-확인-화면--222--s26s27-인계-제안)의 네 경로, 정책 변경 거절, 중복 준비·확정, 영수증 권한과 세션 독립성, COMPLETED 및 FAILED와 계정 이용 종료·데이터 정리의 대응을 확인한다. 계약 변경이 필요할 때만 해당 프론트 분기를 함께 수정한다.

이번 보완은 기존 !146 병합 이후의 복구 결함과 검증 근거를 반영하는 후속 MR로 제출한다. 비작성자 검토·병합과 위 인계 근거 등록 뒤 222를 완료 처리한다. 정책 인계가 확인되기 전에 완료 자동화 문구로 티켓을 닫지 않는다. 실제 쿠키·DB·두 계정·배포의 최종 인수는 기존 244 P1-222에 둔다.
