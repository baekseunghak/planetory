- 개인 지도 2,501개 모두 렌더링, 전체 지도 행성/궤도 0개.
- `/sky?star=1` 선택 시 본인 상세의 5개 행성 모두 표시.
- 새로고침 후 인증과 해당 선택 유지.

고정 선택 URL은 연결 검사이며 205의 클릭·드래그·줌이나 206의 카메라 전환·정보 UI 전체 완료가 아니다. 9/17의 자세한 API 검증과 한계는 [기존 연결 결과](local-validation-201-204-20260917.md)를 따른다.

## 운영과 남은 범위

`VITE_SKY_RENDERER_ENABLED` 기본 false를 유지한다. 활성화는 기존 설정 또는 `npm run build:renderer`를 사용한다. 렌더러 연결을 되돌릴 때는 플래그를 false로 빌드하면 데이터 연결 상태로 복귀한다.

같은 TIC의 신규 발견/locate/저장 좌표 종단 인수, 205·206·207 소비자 연결, 배포 HTTPS·Safari, 비작성자 승인·병합은 [204 인수 기록](ticket-204-readiness.md)에 남긴다. 215의 10만 별 성능 검사는 사용자 결정대로 보류하며 이번 병합 준비의 추가 조건으로 삼지 않는다. MR 승인·병합·Jira 완료 처리는 수행하지 않는다.
