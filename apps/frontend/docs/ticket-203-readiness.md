## 로컬 확인

`apps/frontend`에서 `npm ci` 후 `npm run dev:sky-data`를 실행한다.

주소: http://127.0.0.1:58270/sky

1. 처음에는 전체 별 수와 서버 overview 군집만 보인다. 최종 은하 디자인이 아닌 데이터 검사 화면이다.
2. 배율 단계에서 2를 선택한다. 전체 수보다 적은 현재 영역의 별만 적재된다. 좌우 이동·회전·기울기로 필요한 범위가 달라진다.
3. 적재된 별을 선택하고 `개발 응답 시나리오 → 새 발견 응답`을 누른다. 전체 수와 버전은 바뀌지만 카메라·선택 및 기존 좌표는 유지된다.
4. 2단계에서 `일부 영역 실패`를 누른다. 이미 받은 별은 남는다. `서버 응답 복구 → 실패 영역 다시 불러오기`로 복구한다.
5. 실제 API는 일반 `npm run dev`와 기존 프록시 설정을 사용한다. 실제 세션/API가 없으면 오류를 표시한다. 58270 고정 계정은 운영 인증이 아니다.

## 브랜치와 제출

브랜치는 `feature/S15P21C206-203-web-sky-data`다. 201/202가 미병합이므로 203 초안 리뷰는 202를 임시 비교 대상으로 하여 203 변경만 보여준다. **202로 병합하지 않는다.** 선행 MR이 develop에 반영되면 기준과 대상을 develop으로 정리하고 재검증·리뷰한다. 최종 통합 대상은 팀 규칙대로 develop이다.

로컬 구현·검증이 끝나도 실제 인수·리뷰·병합·결과 등록 전에는 완료로 전환하지 않는다. 백엔드 대기 동안 다음 204를 별도 브랜치에서 진행할 수 있다.
