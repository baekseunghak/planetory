# 219 팔로우 구현과 인계

2026-09-21. develop af29c8e 기준. 사용자는 시제품을 기준으로 프론트를 진행하고 백엔드 AI가 읽을 문서를 함께 작성하도록 요청했다.

- 회원/별 관계 GET·PUT·DELETE, 별도 서버 요약, 내 관계 목록과 팔로잉 피드를 연결했다. 개인정보와 관계 명단의 타인 공개는 확장하지 않는다.
- 커뮤니티 팔로잉과 마이페이지 관계 관리, 프로필/별 게시판 버튼을 시제품 동선에 맞춘다. 서버 실패를0으로 표시하지 않으며 응답 유실 뒤에는 쓰기를 막고 GET 확인을 요구한다.
- [백엔드 인계 계약](../../backend/docs/p1-service-contract.md)은 FE 구현 기준이다. 백엔드 구현·교차 리뷰·실제 인수 완료를 주장하지 않는다.
- 확인 명령: `npm run build`, `npm test`, `npx playwright test --config=playwright.p1.config.ts follow.spec.ts` (Chrome).
- 실제 DB 두 계정·백엔드 페이지/자격·배포 검증은244 P1-219, 백엔드172/173에서 수행한다. 검증 결과는 MR에 기록한다.
