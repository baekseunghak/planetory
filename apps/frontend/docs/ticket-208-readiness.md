## 구현 위치와 데이터 소유권

- `src/features/quests/QuestProvider.tsx`: 화면당 한 공급자. 퀘스트·회차를 각각 읽고 독립 실패 처리한다. 메타/회원 전환 시 이전 응답을 가리고 취소하며, 늦은 응답을 폐기한다. 퀘스트 오류로 별 목록·상세를 막지 않는다.
- `contracts.ts`: 다섯 순번, 잠긴 TIC 비노출, 완료 수/사유, 회차·날짜·참여 수·재개 배열 검증. 서버의 eligible을 직접 계산하지 않는다.
- `QuestPanel.tsx`: 독립 접힘·선택, WebGL 실패 시에도 같은 UI/목록 경로, 실제 보인 안내만 저장. 회차 시간대/종료일 경계가 미확정이므로 날짜를 그대로 표시하고 임의의 카운트다운으로 마감이나 자격을 판단하지 않는다.
- `GalaxyInteraction`과 패널은 같은 퀘스트 상태로 번호/느낌표를 표시한다. 207의 중복 퀘스트 조회/UI를 공용 패널로 옮겼다. 지도 그리기나 입장 확대 애니메이션을 재시작하지 않는다.
- `/me/quests`는 튜토리얼·발견·진행·재개의 원천이다. `/challenges/current`는 새 회차 안내용이다. 후자가 실패해도 전자의 발견 상태를 사용하며 가짜 회차 성공 응답을 만들지 않는다. 조회로 별을 해금하지 않는다.
- 보이는 동안 60초, 홈 진입, 탭/창 복귀에 읽기 갱신한다. 동일 창의 연속 focus/visibility 이벤트는 1초 간격으로 합친다. POST/PATCH 재전송이나 서버 확인 API를 추가하지 않는다.

```ts
import { publishQuestChange } from "./features/quests/events";
```

## 실제 로컬 화면 후속 검증 — 2026-09-17

사용자가 58344 프론트를 직접 실행한 뒤 기존 격리 백엔드854c23c(58342)와 합성 OAuth(58343)에 연결했다. 검증 대상 프론트 코드는126a6165다. 응답 가로채기·대체 없이 기존 신규/기존 합성 검증 회원을 사용하며, DB나 백엔드 설정을 수정하지 않았다.

Chromium·Chrome·Edge·정식 Firefox에서 두 계정 각각 다음7개 확인점, 총56개를 통과했다.

1. 실제 C07 HTTP200 응답과 퀘스트 완료 수 표시가 일치한다.
2. 튜토리얼·챌린지는 각각 기본 접힘 상태다.
3. 다섯 슬롯의 선택 가능 여부가 서버와 일치한다. 신규 회원은1번만 열리고 나머지4개TIC는null이다.
4. 퀘스트의 별 선택으로 실제 상세를 읽고, 돌아오면 누른 버튼으로 포커스를 복원한다.
5. 대체 목록과3D 지도 사이를 전환해도 퀘스트를 이용할 수 있다.
6. S15 회차 API의 실제404는 접힌 챌린지를 펼쳤을 때 안내하며, 가짜 새 회차 알림을 만들거나 지도를 막지 않는다.
7. 처리되지 않은 브라우저 JavaScript 오류가 없다.

현재 격리 서버의 검증 자료는 다섯 슬롯의 intent를 모두 `deep_confirmed`로 반환하므로 이 계정의 학습 목적 문구는 동일하게 표시된다. 프론트가 순번으로 목적을 임의 교체하지 않는다. 다섯 intent별 문구는 개발 fixture 검사에서 확인했으며, 실제 교육 자료 구성이 완성됐다는 증거로 보지 않는다.

현재 확인 주소는 `http://127.0.0.1:58344/sky`다. 기존 로컬 OAuth의 복귀 주소가58341로 등록되어 있어 로그인 후58341로 돌아오면58344를 다시 연다. 같은 호스트의 세션을 사용하며 운영 배포의 로그인 주소 계약 변경이 아니다. 사용자가 실행한 PowerShell 창을 닫으면58344 서버도 종료된다.

이번 확인으로 아래의 **서버 실행 대기와 실제208 화면 미검증 상태는 해소**했다. 실제 분석 제출→다음 튜토리얼, 재개 사건, S15 성공 응답, 실제 분석 화면 왕복·배포 인수까지 완료한 것은 아니다. 체크리스트208-02·03·07·08·09는 관련 미검증 조건을 유지한다.

- 기존 실제 로컬 백엔드(854c23c)의 신규/기존 합성 검증 회원 각각 `/me/quests` HTTP 200과 208 디코더를 대조했다. 신규 회원은 완료 0개·첫 슬롯만 열린 상태·나머지 4개의 잠긴 TIC가 null이다. `/challenges/current`는 두 회원 모두 404여서 168 제공 대기로 구분한다. 이 결과는 HTTP+디코더 검증이며 208 실제 화면 전체 통합 검증은 아니다.

- 실제 백엔드 연결용 로컬 58344 프론트 실행은 자동 승인 검토에 차단되어 사용자 확인을 요청했다. 허용·실행·검증 여부는 후속 기록으로 갱신한다.
