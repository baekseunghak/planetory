## 구현 경계

- `DiscoveredStars.tsx`는 C06 목록과 읽기 전용 퀘스트 접근을 담당한다. 한 화면에 20개만 렌더하고 서버 cursor 이력으로 돌아간다. 새 메타/버전·분석 반환 때 처음부터 갱신한다. 그래픽·타일 실패로 목록 조회를 실패 처리하지 않는다.
- `discovered.ts`는 문자열 TIC·null 곡선 단계·숫자·상태·중복·hasNext/nextCursor 정합과 잠긴 퀘스트를 검사한다. cursor를 해독·생성하거나 page로 바꾸지 않는다.
- `GalaxyScene`은 가용 상태를 부모에 전달한다. 목록 모드에서 같은 캔버스/카메라를 보존하고 그리기·상호작용·타일 범위 변경을 중지한다. 숨긴 지도는 inert/aria-hidden으로 키보드·보조기술 탐색에서 제외한다.
- `StarDetail`은 기존 C06 조회·선택·행성 정보를 재사용한다. 목록에서 분석/결과/게시판 링크의 returnTo는 `view=list`와 TIC를 보존한다. 분석 본문·성과 생성·새 별 좌표·백엔드/DB는 변경하지 않는다.
- 퀘스트는 접힌 안내에서 열린 별의 기존 상세에 접근하는 범위다. 완료·건너뛰기·회차 상세 등 전체 W09 동작은 208이다. 목록에서의 표시 결과를 실제 C07 인수로 간주하지 않는다.
- 206의 적재 별 로컬 검색/50개 페이지는 이번 cursor 발견 목록으로 교체된다. 이전 개인 시제품, 205/206 작업 폴더는 유지한다. 패키지 버전·의존성은 변경하지 않았다.

```powershell
npm ci

```

개발 모드의 HTTP fixture로 같은 제품 컴포넌트를 확인한다. 일반/운영 모드는 실제 API 설정과 기존 VITE_SKY_RENDERER_ENABLED=true를 사용하고 가상 계정/자료/검사 endpoint를 포함하지 않는다. Docker를 새로 실행하거나 설정을 바꾸지 않았다.

Windows 검증: 타입·운영 렌더러 빌드·fixture 제외, 단위67개, 대체 목록 Chromium/Chrome/Edge/정식 Firefox 각각9개, 기존 상세9개·입력8개·은하16개·운영 렌더러2개 통과. 마지막 목록 겹침/퀘스트 위치·복귀 포커스 보완 뒤 Firefox9개, 최종 Chromium 영향5개와 상세3개·타입/운영 빌드를 재확인했다. 모든 검사를 마지막에 한 번에 재실행했다고 주장하지 않는다. 실제 HTTP 검증은 위 207-06 범위다.

실제 Safari·스크린리더·배포·대규모 성능 검증은 이번 작업에 포함하지 않았으며, 이전 215 보류 결정을 변경하지 않는다. 구현 커밋을 되돌리면 206의 적재 별 목록으로 돌아간다. 데이터/스키마 롤백은 필요 없다.
