# 218 핫 토픽 조회·선정 기준 안내

S15P21C206-218 / W20-2 / P0 / 하서진 / 2026-09-20. develop `d252e5e`에서 분기했다. [Jira218](https://ssafy.atlassian.net/browse/S15P21C206-218), [서비스 API 4.2](../../backend/docs/service-api-spec.md), [SRS COM-09](../../../docs/requirements/planetory-requirements-spec.md)의 확정된 유효 참여자 10명 기준을 적용한다. 검색과 일반 피드를 재계산하지 않고 S18을 별도 조회한다.

## 구현과 책임 경계

| 항목      | 구현                                                                                                                                                                                                                                                        |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## 확인 방법

`apps/frontend`에서 `npm ci` → `npm run dev:hot-topics` 후 `http://127.0.0.1:58368/community/hot-topics`를 데스크톱으로 연다. 상단에 합성 응답임을 표시한다. 선정 기준 펼치기, 11명/10명 항목과 오래된 스레드, 상세 이동·이전 화면, 다음 페이지를 확인할 수 있다.

개발 공급자는 24개 합성 스레드 중 N=9인 한 건을 제외한 23개를 20+3개로 반환한다. `/api/dev-hot-topics-218/*`는 테스트 중 응답의 참여자 수·숨김·오류를 바꾸는 개발 전용 경로다. 실제 회원 판단의 DB 집계 구현이나 검증 증거가 아니다. Vite serve의 명시적 `hot-topics` 모드에만 연결되고 운영 빌드·preview에는 포함되지 않는다. 일반 실행에서 API가 없으면 조회 실패를 표시하며 합성 자료로 대체하지 않는다.
