## 기능 범위

- 일반 글과 공식 신호 스레드에서 1단계 댓글 목록·본인 작성/수정/삭제를 제공한다. 개인 공개 분석에 댓글을 붙이거나 답글·반응을 자동 생성하지 않는다.
- 본문 1~2,000 Unicode 코드포인트, 공백만 입력 거절, 줄바꿈·이모지·일반 텍스트, 서버 fieldErrors를 처리한다. 소유권은 서버가 최종 검증하며 화면에는 본인 수정/삭제만 노출한다.
- 최종 등록에서만 POST, 본문이 바뀐 경우에만 PATCH, 삭제 확인 후 DELETE한다. 공통 세션·CSRF·401 처리를 사용한다. 서버가 삭제한 댓글은 목록과 수에 포함하지 않으며 삭제 자리 표시를 만들지 않는다.
- 부모 종류/ID/size에 묶인 불투명 cursor를 사용한다. 다른 부모로 이동하면 초안·확인 상태를 분리한다. 부모 접근 거절 시 본문과 모든 자식 화면을 가린다.
- 탭 복귀 시 부모/목록을 재검증하지만 댓글 입력과 응답 불명확 상태는 유지한다. 로그아웃·401 때 제거하며 localStorage에 저장하지 않는다. 창 닫기/새로고침은 미저장 경고가 있다. 사이트 내 다른 화면으로 떠난 초안의 자동 복원은 제공하지 않는다.
- W14 자료 선택을 위한 `CommentMaterials` 입력 경계를 둔다. 실제 선택·카드·그래프는213에서 연결하며211은 자료 배열을 보내지 않는다.

## 응답 불명확 복구

S06에는 `GET /comments/:id`가 없다. 임의 API를 추가하지 않고 `GET /comments?parentType&parentId&size&cursor`로 확인한다.

1. POST/PATCH/DELETE 응답 유실이나 잘못된 성공 DTO는 자동 재전송하지 않는다. 버튼을 잠그고 입력을 보존한다.
2. 최신 댓글부터 이전 페이지를 수동으로 확인한다. 부모 권한을 먼저 재확인한다.
3. POST는 같은 내용·작성자가 보여도 그 요청의 성공이라고 단정하지 않는다. 중복 위험을 확인한 뒤에만 직접 재편집할 수 있다.
4. PATCH는 댓글 ID로 찾은 현재 본문과 보낸 입력을 비교한다. 현재 서버 내용을 보고 내 입력으로 편집을 계속하거나 종료한다. 다른 창의 저장과 지연 요청 가능성을 안내한다.
5. DELETE 유실 후 미조회는 삭제 성공으로 단정하지 않는다. 현재 조회되는 본인 댓글만 확인 후 직접 재삭제할 수 있다. 본인 반복 DELETE204는 기존 서버 계약을 따른다.
