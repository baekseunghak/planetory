## 수정한 동작

1. 챌린지 느낌표를 타일 `marker` 대신 `/me/quests.challenge.unlocked/ticId`에서 가져온다. 최초 발견 이유가 튜토리얼/성과여도 현재 회차 대상이면 표시한다. 조회 실패나 회차 종료 때는 숨긴다. 개발용 타일 응답의 잘못된 챌린지 마커도 제거했다. 205의 `fda5971`을 206→207에 병합했다.
2. 목록↔지도 전환 때 URL의 `view`와 선택 TIC를 함께 갱신한다. 목록을 닫고 새로고침하면 다시 목록으로 돌아가던 문제를 수정했다.
3. 목록에서 고른 TIC를 URL에도 저장한다. 분석 링크로 이동한 뒤 브라우저 뒤로가기로 복귀할 때 선택이 사라지던 문제를 수정했다. 분석 본문·서버 판정·DB 스키마는 수정하지 않았다.

## 검증 환경과 증거

- Windows, Node24.18.0, Java21, 실제 Spring 백엔드 `854c23c`, 기존 격리 PostgreSQL17.10 DB. Docker를 새로 기동하거나 설정하지 않았다.
- OAuth 제공자·별/행성 데이터만 합성이다. 실제 HTTP 응답을 가로채지 않았다. 신규 회원은 최초 실제 등록 후 브라우저별 재사용했다. 실제 Google/SSAFY 동의 재검사가 아니다.
