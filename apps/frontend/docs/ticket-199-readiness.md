## 구현과 범위

`VITE_P1_ENABLED=true`일 때 `/statistics`에 전체 통계 화면을 등록한다. 인증된 회원이 `GET /api/v1/statistics`를 쿼리 없이 호출한다. 공통 인증·읽기 모델을 사용하여 이탈·세션 변경·탭 복귀 때 이전 조회를 취소하거나 다시 읽으며 영속 캐시를 두지 않는다. 새로고침은 집계 실행 요청이 아니라 마지막 성공본의 재조회다.

발견·시작·현재 완료, 성과와 고유 신호 유형, 첫 매칭 일치율, 공개 판단, 8주 제출 추이, 공개 원글 상위 별, AI 자료 상태, 챌린지와 Sector 완료율을 표시한다. 기존 최소 스타일을 재사용하며 새 차트 의존성은 추가하지 않는다. 개인 통계(198)와 비교 중앙값(200)은 분리하고 `comparison` 블록은 소비하지 않는다. API·SQL·DB·스케줄은 변경하지 않는다.

## 값과 시각

- READY는 성공 집계, STALE은 마지막 성공본의 값·asOf·generatedAt 유지와 갱신 지연, UNAVAILABLE은 최초 성공 집계 없음으로 표시한다. 조회 실패를 STALE이나 정상 0으로 대체하지 않는다.
- 전체 지표가 공유하는 원천 기준 시각과 집계 완료 시각을 KST로 표시한다. 전체 10분 집계와 결과·공식 스레드의 실시간 통계가 다름을 안내한다. 화면에서 시간을 새로 만들어 붙이거나 자동 집계 완료를 보장하지 않는다.
- 서버 value를 재계산하지 않고 표시만 소수 첫째 자리로 반올림한다. 비율은 분자·분모를 함께 표시하며 정상 0과 분모 0의 표본 없음을 구분한다.
- 회원×별·고유 TIC, 회원×신호 성과·고유 신호를 구분한다. 성과 유형은 인정 당시, 신호 유형은 현재 분류다. 현재 완료는 재개 시 감소할 수 있다.
- 공개 판단은 회원×신호 대표 참여다. 챌린지는 활성 회차 대상 별의 전 기간 공개 참여이며 고유 참여자와 참여 건수를 구분한다. Sector는 발견 집합 내 현재 완료율로 회차끼리 합산하지 않는다.
- 8주 추이는 KST 월요일 시작, 마지막 부분 주와 빈 주 0을 유지한다. 막대와 같은 값을 의미 있는 HTML 표로 제공한다. 상위 별은 실제 별 게시판 경로로 연결한다.
- 현재 AI 계약은 NO_SAMPLE/AI_ATTEMPT_UNKNOWN이다. `aiAttemptUnknown`은 AVAILABLE이면서 사유가 있으며 전체 공개 참여와 같은 건수다. 이 예외를 전체 파서에만 적용하고 기존 개인 파서를 느슨하게 만들지 않는다. 확률·실패·미실행을 추정하지 않는다.
- policyVersion은 특정 날짜와 비교하지 않고 비어 있지 않은 식별자로 보존한다. 필수 필드·단위·상태·숫자·문자열 ID·주 경계가 손상되면 조회 오류로 처리한다.

- 최종 숫자 형식 보완 후 타입 검사와 Chromium 6개를 다시 확인했다. 1024px 전체 페이지 캡처를 검토했다.
- web-design-guidelines로 표 caption·행/열 헤더, 의미 있는 버튼·링크, 키보드 포커스, 알림 밖 재시도 버튼, 숫자 정렬·서식, 빈 상태와 넘침을 확인했다. 실제 스크린리더 검증은 하지 않았다.

```powershell
cd apps/frontend
npm ci --ignore-scripts
npx playwright test --config=playwright.global-statistics.config.ts --project=chromium
```

테스트는 profiles 개발 모드·P1 활성화·58399 포트를 사용한다. 실행 중인 동일 테스트 서버가 있으면 재사용하며 CI는 새로 실행한다. 이번 검증은 수동으로 실행한 동일 서버를 재사용해 테스트 명령의 정상 종료를 확인했다.

`tests/fixtures/global-statistics.ts`는 백엔드 V21 MV JSON 필드와 서비스 블록을 따른 합성 응답이다. 정상 예시는 발견 30 회원×별/고유 별 15개, 공개 판단 8/4/3건, 8주, 상위 별·Sector·챌린지를 포함한다. 빈 예시는 건수 0·비율 null, 집계 전 예시는 data와 시각 null이다. 브라우저 테스트에서만 HTTP를 가로채며 운영 코드에는 샘플 대체 경로가 없다. 일반 개발 서버를 열기만 해서는 이 샘플 통계가 공급되지 않는다.

## 실제 인수 대기

추가 연결 검토에서 메뉴·라우트·공통 API 클라이언트·인증 취소·백엔드 서비스와 V21 payload를 대조했다. 타입·diff 검사와 개인 통계 5개 + 전체 통계 6개 Chromium 회귀 검사가 통과했다. 제품 코드 변경 없이 같은 profiles/P1 서버에서 두 테스트 묶음을 실행했다.

현재 프론트 Dockerfile에는 `VITE_P1_ENABLED` 빌드 ARG가 없다. 기본 Docker 빌드는 P1 화면을 활성화하지 않는다. 운영 공개 시 빌드 인자와 CI 전달 경로를 별도로 연결해야 하며 컨테이너 실행 환경변수만 추가해서는 이미 빌드한 Vite 앱에 반영되지 않는다. 이번 작업은 기존 P1 게이트를 유지하며 배포 설정을 변경하지 않는다.

승인된 테스트 환경에서 실제 GET과 DB 집계를 대조해야 한다. 최초 MV 적재 전후, 정상 0과 분모 0, 10분 갱신 전후·지연 시 원래 시각, 탈퇴 기여의 다음 성공 집계 제외, 실제 별 게시판 접근, 챌린지 전 기간 모수와 Sector 중복 제거를 확인한다. 서버 운영 스케줄 활성화, 실제 계정·배포 환경, 다른 브라우저와 스크린리더 검증은 수행하지 않았다. Jira 완료·커밋·푸시는 별도다.
