# Google OAuth 실제 검증 · 2026-09-15

## 결과

**실제 Google 계정으로 최초 가입·회원 정보 조회·로그아웃·재로그인 검증에 성공했다.**

- 대상: [로그인 MR !42](https://lab.ssafy.com/s15-bigdata-dist-sub1/S15P21C206/-/merge_requests/42), 원본 커밋 `d50c75e3a662bd3b9cf61780b0df23f8f6909eb2`.
- 최신 커밋의 원본 소스로 Java 21 `bootJar`를 빌드했다. 실행 이미지 이름은 기존 Java 런타임을 재사용한 것이며, 실제 실행 JAR는 위 최신 커밋의 산출물을 읽기 전용으로 연결했다.
- Google 실제 인증·토큰 검증을 사용했다. 테스트 제공자·응답 가로채기·인증 우회는 사용하지 않았다.
- 201 프론트의 기존 빌드와 localhost:8080 Nginx를 사용했다. 프론트나 MR 구현 코드는 수정하지 않았다.
- 사용자가 계정을 선택하고 이름·프로필 사진 제공에 명시적으로 동의했다. 자격 증명과 개인정보는 이 기록에 남기지 않는다.

## 환경과 한계

Google 전용 새 DB `planetory_201_google`에서 V1~~V4 마이그레이션 성공을 확인했다. 튜토리얼 데이터는 MR 자동 테스트와 같은 가상 TIC 1~~5를 넣었다. 기존 SSAFY 회원 및 DB는 변경하지 않았다.

이는 실제 Google 로그인과 서비스 내부 가입·세션 처리를 확인한 결과다. 실제 은하 배치 계산(139번), 운영용 튜토리얼 데이터, 배포 HTTPS까지 확인한 결과는 아니다. 첫 별은 현재 MR의 임시 배치 구현에 따라 원점에 저장된다. Google 측 인증 단계에서 이름·프로필 사진 접근을 허용했으나 해당 개인정보를 검증 보고서·로그에 복사하지 않았다.

앞선 실제 SSAFY 검증은 MR의 이전 커밋 `1cf1cca` 기준이다. OAuth·세션 코드는 최신 커밋에서도 동일하지만, 두 제공자가 모두 최신 커밋으로 실검증됐다고 기록하지 않는다.
