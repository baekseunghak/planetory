## 구현 범위

기존 본인 프로필의 statistics 슬롯에 현재 개인 지표, 성과·등급·판단 분포, 최근 8주 제출 추이, 유효 근거와 제외 건수, 서버의 nextGoal을 표시한다. VITE_P1_ENABLED=true일 때 슬롯을 등록하며 서버의 인증·권한 판정은 그대로 적용한다. 타인 프로필은 개인 통계를 요청하지 않는다.

GET /api/v1/me/statistics의 current만 소비한다. comparison은 200, 전체 통계는 199 범위로 남긴다. 새 의존성·서버 API·DB 변경은 없다. 원본 197 워크트리와 안내 코드는 수정하지 않는다.

## 값과 기간

서버의 value를 재계산하지 않고 소수 첫째 자리까지만 표시한다. numerator/denominator를 함께 제공하며 AVAILABLE 0, NO_SAMPLE, MISSING_BASIS를 구분한다. 알려진 응답 필드만 선택하며 필수 필드 누락·손상된 주 경계·잘못된 근거 집합은 조회 실패로 처리한다. 통계 준비 실패를 0으로 채우지 않는다.

UTC 시각은 Asia/Seoul로 표시하고 조회 기준·생성 시각·가입 이후 누적 기간을 분리한다. 오름차순 8개 주를 그대로 표시하며 월요일 시작 포함·다음 월요일 끝 제외, 현재 주 partial과 빈 주 0을 보존한다. 막대 길이만 표시 영역에 비례하며 통계 산식은 만들지 않는다. 숫자·근거 표는 키보드로 접근 가능하고 막대는 장식으로 처리한다.

일치율은 첫 매칭 기록과의 일치이며 실력·순위·맞춘 개수로 표현하지 않는다. 완료 수는 ‘탐색 완료한 별’이며 재개에 따른 감소와 튜토리얼 누적 완료의 차이를 설명한다. 근거는 oddeven/secondary/ushape만 허용하며 centroid를 추가하지 않는다.

## 검증과 재현

- npm run build: 성공. 기존 fixture 파일 확장자·500kB 번들 경고 유지.
- npm test: 431건 통과(신규 파서 4건 포함).
- npm run typecheck: 최종 변경 후 통과.
- Chromium 개인 통계 5건: 정상·초기·503 재시도·403·손상 응답·지연 조회 이탈·타인 프로필 미요청·1024px·표 포커스 통과.
- 최초 이탈 검사의 ‘GET 정확히 한 번’ 기대는 개발 StrictMode의 추가 읽기/취소를 고려하지 못해 실패했다. 타인 프로필에서 조회가 없는지와 늦은 값 미노출을 검사하도록 수정 후 통과했다.
- web-design-guidelines를 기준으로 표 제목·열/행 헤더·키보드 포커스·오류 알림과 별도 재시도 버튼·숫자 정렬·가로 넘침을 검토했다. 실기기 스크린리더 검증은 하지 않았다.

```powershell
npx playwright test --config=playwright.statistics.config.ts --project=chromium
```

설정은 profiles 개발 서버 58398과 P1 활성화를 사용한다. 테스트의 `tests/fixtures/personal-statistics.ts`는 서비스 DTO를 근거로 한 합성 입력이며 실제 운영 계정 자료가 아니다. 정상·분모 0·과거 기록 부족·빈 주와 기준 시각이 명시되어 있다. 비교 블록은 소비하지 않으므로 합성 입력에 필요한 최소 메타데이터만 둔다.

Windows에서 관리형 테스트 서버 종료가 지연돼 최초 시나리오 통과 로그 후 프로세스가 남았다. 기존 서버에 webServer 없이 연결한 로컬 설정으로 최종 5건을 실행해 exit 0을 확인했다. 기본 명령의 정상 종료와 테스트 시나리오 통과를 구분한다.

## 실제 인수 대기

실제 API의 초기/누적 계정, 인증 만료·재로그인, DB 원본과 숫자/기간 대조는 실행하지 않았다. 승인된 테스트 계정·환경에서 실제 GET 결과와 화면 값을 대조해야 한다. 운영 활성화와 전체 브라우저/스크린리더 인수는 완료로 주장하지 않는다. Jira 완료 처리·커밋·푸시는 별도 요청으로 진행한다.
