## 시제품과 동일하게 만드는 기준

시제품을 화면 배치·문구·시각 효과·조작의 기준으로 삼고, 제품의 실제 API·회원 권한·오류·개인 자료 경계는 유지한다. 시제품의 가상 계정·성과 지급·샘플 응답을 운영 코드로 옮기는 작업이 아니다. 실제 별·행성의 수치와 개수는 서버 응답을 따르므로 샘플 데이터와 수치까지 같아야 한다는 의미도 아니다.

시제품이 이미 표현하는 모양을 문장 명세만으로 새로 해석해 다시 그리지 않는다. 승인된 시제품 코드와 캡처를 함께 비교한다. 관련 시각 자료는 [승인된 은하 기준](../../../docs/development/sky-reference/README.md)에 있다.

| 드래그·축소    | 상세의 로컬 회전·확대, 계속 축소하면 행성 → 항성계 → 별지도                    | 현재 은하 카메라 조작을 그대로 재사용하는 것과 다르다. 전환 임계값, 복귀 상태까지 비교한다.                             |

## 명세·티켓에서 정리할 내용

- **그대로 지킬 것:** 같은 은하 canvas의 근접 뷰, 실제 소유 행성만 표시, 식별자·종류·주기·깊이, 분석/결과/스레드 연결, 오류·빈 상태 구분, 과거 응답 차단, 원래 카메라·키보드 초점 복원, WebGL 대체 목록, 데스크톱 지원 안내.
- **구현 배치로 해결할 것:** HOME-08의 비가림 조건은 현재 도킹 패널 모양을 강제하지 않는다. 시제품의 가장자리 정보와 천체 공간을 배치하면 충족할 수 있다.
- **문구를 통일할 것:** HOME-08, 별지도 표현 계약 3절, 와이어프레임의 `은하로 돌아가기` → `별지도`, `별 전체 보기` → `항성계 전체`. 두 기능의 구별은 유지한다.
- **동작 변경을 명시할 것:** 시제품 그대로 진행하는 경우 빈 하늘 클릭은 상세 유지로 바꾼다. `별지도`/Escape/계속 축소가 복귀 동작이며, 항성계/항성/행성 탭과 단계별 축소 전환을 정본에 기록한다.
- **티켓 처리:** 248에 상세의 시제품 일치와 시각 대조를 완료 조건으로 남긴다. 기존 205/206의 구현 이력을 지우거나 새 API 기능이 필요하다고 간주하지 않는다. 미완료 `219`~`223` 등의 기능은 원래 티켓에서 같은 시제품 기준으로 진행한다.

이 문서는 목표와 차이를 기록한다. 상세 뷰 이식·명세의 위 동작 변경은 아직 적용하지 않았으며, 버그 수정만으로 시제품 일치 완료라고 보고하지 않는다.

## 간헐 실패 원인과 수정

기존 develop 미리보기(`508578b`)에서 Chrome으로 원래 별 상세 9개 묶음을 실행해 첫 실행 9개 통과, 두 번째 실행 1개 실패/8개 통과를 재현했다. 별도 임시 계측에서도 같은 실패를 재현했다. 캡처와 기존 테스트를 제거하거나 제한 시간을 늘리지 않았다.

실패한 실행의 계측 순서:

```text
1327.7ms  resize: 1440×1000 → 1×1
1327.9ms  DesktopGate: max-width 1023px = true
1329.8ms  useSkyData cleanup: 선택한 별을 가진 store 폐기
1334.5ms  resize: 1×1 → 1440×1000
1338.5ms  useSkyData mount: 새 store 생성
1342.0ms  URL /sky에서 선택 TIC를 찾지 못해 select(null)
```

이 구간에는 별지도 복귀 버튼이나 빈 하늘 클릭 입력이 없었다. full-page 캡처 중 일시적인 뷰포트 변화에 `DesktopGate`가 페이지 전체를 언마운트하는 것이 확인된 직접 원인이다. 30초는 GPU가 그 시간 동안 멈췄다는 증거가 아니라, 이미 없어진 버튼을 기다리다가 도달한 테스트 제한 시간이다.

수정은 `App.tsx`의 `DesktopGate`에서 수행한다. 데스크톱으로 한 번 진입한 페이지는 작은 화면에서 `hidden`·`inert`로 숨기고 비활성화하되 유지한다. 처음부터 작은 화면이면 제품 페이지를 아직 만들지 않는다. 인증 만료 시에는 기존 `ProtectedRoutes`가 비공개 페이지를 제거한다. 선택 TIC를 가짜로 복구하거나 사용자별 자료를 전역 저장하지 않는다.

`tests/detail/viewport.spec.ts`에 1×1 및 767px 축소 → 복귀 → full-page 캡처 → 원래 지도 복귀 검사를 추가했다. 수정 전에는 동일 canvas 연결 검사에서 즉시 실패했다. 작은 화면 최초 진입과 숨김 중 401 자료 정리도 검사한다. 기존 좁은 화면 검사는 DOM 삭제 대신 비노출을 확인하도록 맞춘다.

최종 실행 결과(Windows, Chrome, 2026-09-21):

- 수정 전 새 viewport 재현 검사: 기존 canvas가 제거되어 즉시 실패.
- 수정 후 기존 상세 9개 + viewport 회귀 2개 전체 묶음: 6회 연속 11개 통과, 총 66건. 기존 full-page 캡처·30초 제한 유지, 실패 재시도 없음.
- 공통 기반 6, 인증 9, 핫 토픽 10, 배치 6: 총 31건 통과. 열린 모달의 좁은 화면 비노출·데스크톱 복귀와 숨김 중 세션 만료도 확인했다.
- `npm run build`: 타입 검사·운영 빌드·개발 fixture 제외 검사 통과. 기존 500KB 청크 경고는 남아 있다.
- `npm test`: 단위 340개 통과.
- 임시 계측을 넣었던 develop 미리보기의 소스는 원복했다. 수정은 248 브랜치에만 남긴다.

이는 확인한 페이지 재생성 원인에 대한 회귀 검증이다. 향후 모든 환경에서 간헐 실패가 절대 없다고 주장하지 않는다. 실제 운영 API 인수나 시제품 상세의 외형 일치 완료를 뜻하지 않는다.

## 2026-09-21 후속 반영
기존 표는 착수 시점 비교다. 이번 후속에서 자체 천체 표면·조명, 항성/행성 선택, 회전·휠 확대, 항성계 전체 보기, 별지도 복귀를 같은 캔버스에 반영했다. 상세 빈 곳 클릭은 유지하며 왼쪽 정보와 오른쪽 천체를 구분한다. 실측 수치와 서버 행성 배열 검증은 유지한다. 로딩/오류/그래픽 폴백은 기존 목록을 계속 사용할 수 있다. 백엔드 API 변경은 없다.


검증(2026-09-21): Chrome 별 상세11개·검색8개·퀘스트11개 통과. 폴백11개 중 목록 전환/실제 그래픽 context 복구2개 가림을 수정하고 재검증2개 통과(나머지9개 첫 실행 통과). 시제품 천체와 기존 HTTP·권한·복귀 경로를 함께 확인했다.
