# 이전 군집 비교 실험 보관

2026-09-15 군집 제거를 결정할 때 사용한 개발 전용 화면이다. **현행 별지도는 개별 별 v1.3**이며 [204 렌더러 계약](galaxy-renderer.md)을 따른다.

`npm run dev:galaxy` 후 `/dev/galaxy-comparison`을 연다. 이번 서버는 `http://127.0.0.1:58275/dev/galaxy-comparison`이다. 기존 `/sky`의 개발 도구에 보관본 링크가 있다.

- 왼쪽은 당시 합성 좌표를 개별 표시하고, 오른쪽은 당시 군집/LOD로 표시한다. 카메라·휠·드래그·키보드는 두 화면에 같이 적용한다.
- 기존 셰이더·모델·검증기·fixture를 `dev/legacy-galaxy`로 옮겨 당시 화면과 실험 결과를 보존했다. 현재 운영 `src`는 이를 import하지 않는다.
- 비교 API는 `/api/dev-legacy-galaxy-204/dev-galaxy-204/comparison`이다. 한 스냅샷을 두 화면에 같이 쓰며 현재 `/sky`의 개발 계정/좌표/버전을 변경하지 않는다.
- 기존 별1000개·0단계 군집32개의 합성 자료다. 원본 개인 시제품 좌표·외형과 다르므로 최종 은하 외형 검증에 사용하지 않는다.
- 당시 별400/궤도별60/성운80 상한과 성운 경로는 보관 코드에만 남는다. 현재 별지도에서 복원하거나 군집 적용의 근거로 삼지 않는다.
- 두 렌더러를 동시에 실행하므로 성능 비교나10만 별 인수에 사용하지 않는다.

검사4개는 동일 스냅샷/계정 불변, 동기 조작/크기, 자동LOD/고정군집/궤도, 실패 후 복구를 확인한다. 현행 검사에서도 재통과했으며 정확한 브라우저별 결과는 [204 인수 기록](ticket-204-readiness.md)을 따른다. 개발 경로/전체 원본 API는 운영에서 제외한다.
