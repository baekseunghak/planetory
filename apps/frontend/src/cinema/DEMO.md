# 발표 시연 안내 (발표자 노트북)

시연은 `npm run dev:cinema` 개발 서버 하나로 한다. 로그인·은하·커뮤니티는 이 노트북 메모리 안의 합성 자료이고, 튜토리얼·탐사 별 10개는 실제 TESS 관측 자료다. 실제 서버·DB는 쓰지 않는다.

## 준비물

- Node 22.12 이상, Chrome(설정 → 시스템 → "가능한 경우 그래픽 가속 사용" 켬. `chrome://gpu`에서 WebGL이 Hardware accelerated인지 확인).
- 화면 폭 1024px 이상(권장 1920×1080 또는 1440×900), 브라우저 확대 100%.
- `apps/frontend/.real-sample/`(실제 별 10개). 없으면 [`tools/real-sample/README.md`](../../../../tools/real-sample/README.md)로 발표장 오기 전에 만든다(MAST 다운로드가 필요하다).

## 띄우기

```bash
cd apps/frontend
npm ci                 # 처음 한 번
npm run dev:cinema     # http://127.0.0.1:58390
```

- 시작 줄에 `real TESS sample 10 stars`가 보여야 한다. `합성`만 보이면 `.real-sample/`이 없는 것이다.
- 포트가 겹치면 `CINEMA_PORT=58391 npm run dev:cinema`(PowerShell: `$env:CINEMA_PORT=58391; npm run dev:cinema`). 아래 주소의 포트도 바꾼다.
- 분석 화면은 새 디자인이 기본이다(운영과 같다, 시작 줄에 `analysis new`). 예전 기존형과 나란히 비교할 때만 두 번째 서버를 `CINEMA_PORT=58391 CINEMA_ANALYSIS=classic CINEMA_HMR=0 npm run dev:cinema`(PowerShell: `$env:CINEMA_PORT=58391; $env:CINEMA_ANALYSIS="classic"; $env:CINEMA_HMR="0"; npm run dev:cinema`)로 띄운다. 어느 서버에도 토글은 없다. 두 서버는 세계를 따로 들고 있으니 시나리오 주소를 각 포트로 연다(예: `http://127.0.0.1:58391/api/dev-cinema/session?as=newcomer&start=login`). `CINEMA_HMR=0`은 소스가 바뀌어도 열린 화면을 다시 불러오지 않는다.
- 리허설 확인(선택, 세계를 바꾸므로 발표 전에): 다른 터미널에서 `CINEMA_PORT=58390 node scripts/cinema-smoke.mjs` → `5/5 passed`.
- DEMO 탭은 화면에 보이지 않는다. 위 가운데에 마우스를 올리거나 Alt+Shift+D로 연다.

## 시나리오 1 — 처음 온 탐사자 (실제 별 WASP-62에서 발견)

주소: `http://127.0.0.1:58390/api/dev-cinema/session?as=newcomer&start=login`
(또는 DEMO 탭 → `로그인 화면에서 시작` 체크 → `처음 온 탐사자`)

1. `SSAFY 계정으로 로그인` → 멀리 있는 은하 위로 네 줄의 이야기가 하나씩 나온다(약 10초, 회원마다 한 번) → `시작하기`(오른쪽 아래 `건너뛰기`나 Escape로 바로 넘어가도 된다) → 은하로 날아드는 장면이 파란 1–5 표시가 모두 화면 안에 든 구도로 끝나고, 튜토리얼 1(TIC 149603524 = WASP-62)로 스스로 날아간다(회원마다 한 번). 이야기를 다시 보려면 시나리오 주소를 다시 연다.
2. (선택) 패널의 `← 나의 은하` → 은하에 머문다("파란 1번 별을 눌러 시작하세요."). 파란 1–5 마커를 보여 주고 `1` 마커를 누른다.
3. `분석 시작`(새 디자인).
4. 아래 패널의 `1위` 봉우리 칩(4.4118일)을 누른다. 가운데에 접힌 곡선이 나온다.
5. 접힌 곡선의 깊은 골(위상 약 0.71, 왼쪽 복제는 약 -0.29)을 골 폭보다 조금 넓게 왼쪽에서 오른쪽으로 드래그한다(골이 좁으면 휠로 확대). 구간이 `0.69–0.74` 정도로 잡히면 된다.
6. 오른쪽 판단 칸의 `행성 같음` → `제출값 확인` → `제출하기`.
7. 통과 장면(1초 뒤 오른쪽 아래 `건너뛰기` 또는 Escape로 바로 카드) → 카드 "알려진 행성 WASP-62 b를 직접 찾아냈습니다 · 행성 1 · 주기 4.412일 · 지속 3.0시간 · 깊이 1.32%" → `은하로 돌아가기` → 새 별 점화(TOI-270, 빨간 `!`). 상단 발견한 별 5 → 6.
8. (선택) 새 별을 눌러 TOI-270 패널을 보인다.

- 1440×900과 1024×768에서 주기도, 접힌 곡선과 판단 칸의 버튼(제출값 확인·제출하기)이 스크롤 없이 보인다. 위 띠의 튜토리얼 풀이는 `풀이 닫기`로 닫는다.
- 구간이 골을 비켜 가면 "이번 구간에서는 신호를 찾지 못했습니다"와 함께 판단 칸에 `구간 다시 잡기`(주기를 둔 채 구간 단계로)와 `주기 다시 고르기`가 나온다. 골을 다시 잡아 제출한다.
- `아닌 것 같음`을 고르면 "구간은 맞았고, 판단은 달랐습니다" 카드가 나온다(성과 미인정, 점화 없음).
- 결과는 판단 칸에 한 줄로 남고, `결과 자세히 보기`(카드의 같은 버튼)가 결과 화면을 연다. 행성이 여럿인 별(튜토리얼 2·5)은 결과의 `다음 곡선 단계로`로 이어 간다.
- 기존형(`CINEMA_ANALYSIS=classic` 서버)에서는 4–6이 단계별이다: `1위 봉우리 선택` → `이 주기로 구간 선택` → 골 드래그(`선택 위상 0.69–0.74`) → `구간 확정하고 판단하기` → `행성 같음` → `제출값 확인` → `제출하기`.

## 시나리오 2 — 오래 탐사한 회원 (큰 은하)

주소: `http://127.0.0.1:58390/api/dev-cinema/session?as=veteran&stars=10000` (가볍게는 `stars=5000`)

- 상단 발견한 별 10,000 · 찾은 행성 1,531. `전체 보기`, 별 하나를 눌러 항성계로.
- 실제 별로 보여 줄 때: `/sky?star=307210830`(L 98-59, 행성 3개) → `행성 1` → `NASA 행성 자료 보기`. `분석 결과 보기`는 신호 3개와 기록·곡선으로 이어진다.
- 메뉴 → 마이페이지: 내 별, 내 분석 기록(실제 별 제출 기록), 통계. 합성 별의 행성은 "NASA 자료에서 연결된 행성을 찾지 못했습니다"로 나오므로 NASA 설명은 실제 별에서 보인다.

## 시나리오 3 — 다른 탐사자의 은하

- 메뉴 → 커뮤니티 → 글쓴이(예: 행성사냥꾼) → 프로필 `은하 방문하기` → 읽기 전용 은하. 별을 누르면 그 사람이 찾은 행성을 본다.
- 바로 가기: `/members/u-302/sky`(2,400개), `/members/u-303/sky`(10,000개), `/members/u-301/sky`(50개), `/members/u-210/sky`(비공개 안내). 왼쪽 아래 `다른 탐사자`, 왼쪽 위 `← 나의 은하로`.

## 처음으로

- 같은 시나리오를 새로: 시나리오 주소를 다시 열거나 DEMO 탭 `지금 세계 처음으로`(또는 `curl -X POST http://127.0.0.1:58390/api/dev-cinema/reset`).
- 새 세계마다 제출 번호가 새로 시작하므로 통과·점화 연출은 리허설 뒤에도 다시 나온다.
- 서버를 다시 띄우려면 Ctrl+C 뒤 `npm run dev:cinema`.

## 그래픽이 느릴 때

1. 오른쪽 아래 `빛 효과 켬` → `끔`.
2. 그 탭에서 한 번 `http://127.0.0.1:58390/login?power=reduced`(더 낮게 `low`)를 연 뒤 시나리오를 진행한다. 이 탭에서는 계속 그 단계로 그린다. 되돌리기는 `?power=auto`.
3. 마지막 수단 `?power=list`: 3D 대신 별 목록.

소프트웨어 그래픽(원격 데스크톱 등)이면 저절로 낮은 단계로 그린다. 은하를 그리는 동안 느려지면 "화면이 느려 그래픽을 낮췄습니다"가 잠깐 보인다.
